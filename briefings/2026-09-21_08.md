## 1. StepFun `Step 5 Preview` — 600B MoE·1M Context, Agent 작업을 정면으로 겨냥

![StepFun](https://36krjp-1316517779.cos.ap-tokyo.myqcloud.com/uploads/2026/05/20260525194139screenshot525.png)

### 핵심 요약

StepFun이 9월 20일 새 Flagship Model `Step 5 Preview`를 공개했다. Sparse Mixture-of-Experts 구조로 **총 600B Parameter 가운데 Token당 27B만 활성화**하며, **1M Token Context와 Vision Input**을 지원한다. 회사는 Software Engineering, Long-horizon Agent Task, Professional Knowledge Work와 Finance를 핵심 목표로 잡았다.

StepFun 자체 평가에서 DeepSWE v1.1은 67.7%, Terminal-Bench v2.1은 85.0%를 기록했다. 자체 구축한 StepCodeBench는 553개 Repository, 9개 Task Category, 20개 Application Domain, 33개 Programming Language를 포함하며 Step 5 Preview는 avg@4 49.0%를 기록했다. 24시간 동안 H100의 MLA Kernel을 자율 최적화하는 실험에서는 508 TFLOPS까지 도달했다고 보고했다. 이 수치들은 출시사 측 평가이므로 독립 검증과는 구분해서 볼 필요가 있다.

API는 현재 제공되고 있으며 Vercel AI Gateway 기준 가격은 입력 100만 Token당 $1, 출력 $2.70이다. StepFun은 **10월 15일 Open Weight 공개**를 예고했다.

### 왜 중요한지

중국의 Frontier Model 경쟁이 단순 Benchmark 추격에서 **장시간 Tool 사용과 실행 Feedback을 포함하는 Agent Runtime 성능**으로 이동하고 있다. 특히 600B의 큰 Parameter Pool을 유지하면서 실제 Token당 활성 Parameter를 27B로 줄이는 구조는 비용과 성능의 Pareto Frontier를 노린 전략이다.

더 중요한 것은 공개 Weight가 예정돼 있다는 점이다. 성능이 독립적으로 검증된다면 Qwen·DeepSeek·Kimi·GLM에 이어 **고성능 Open-weight Agent Model의 선택지가 하나 더 늘어난다.**

Sources: [StepFun 공식 발표](https://www.stepfun.com/step-5-preview) · [Vercel AI Gateway](https://vercel-docs.vercel.sh/ai-gateway/models/step-5-preview)

## 2. `Qwen-Image-2.1` — 7B DiT, Native RGBA와 최대 10장 Reference Editing

![Qwen](https://www.searchyour.ai/archivos/qwen-ai-logo.jpg)

### 핵심 요약

Alibaba Qwen이 9월 20일 `Qwen-Image-2.1` Weight를 Hugging Face와 ModelScope에 공개했다. Text-to-Image와 Image Editing을 하나의 모델에서 처리하며, 시각 생성부는 **32-layer·7B Single-stream DiT**다. Text와 Condition Image를 읽는 Encoder에는 Qwen3-VL 8B가 사용된다.

이번 버전에서 눈에 띄는 기능은 **Native RGBA Transparency**, 최대 **10개 Reference Image**, Circle·Painted Annotation·Mask를 통한 Local Editing이다. VAE 자체가 Alpha Channel을 포함한 64-channel RGBA 구조라 배경 제거를 후처리로 흉내 내는 것이 아니라 투명 이미지를 직접 생성·편집할 수 있다.

생태계 지원도 출시 당일부터 붙었다. Diffusers의 `QwenImage21Pipeline`, ComfyUI Native Support, vLLM-Omni, SGLang, LightX2V가 Day-0 지원을 제공한다. 다만 Weight를 내려받을 수 있다고 해서 자유로운 상용 Open Source는 아니다. **Qwen Research License**가 적용되며 상업적 사용에는 별도 허가가 필요하다.

### 왜 중요한지

이미지 모델의 경쟁 기준이 단순 Text-to-Image 품질에서 **편집 가능한 Production Asset 생성**으로 옮겨가고 있다. 투명 배경, 다중 Reference, 국소 수정은 광고·상품 이미지·게임 Asset·디자인 Workflow에서 바로 필요한 기능이다.

또한 모델 공개 당일부터 ComfyUI, Diffusers, vLLM, SGLang이 붙었다는 점은 이제 Foundation Model 자체뿐 아니라 **출시 첫날 Runtime 생태계가 얼마나 빨리 움직이는가**가 확산 속도를 결정한다는 것을 보여준다.

Sources: [Qwen-Image-2.1 GitHub](https://github.com/QwenLM/Qwen-Image-2.1) · [Qwen Research License](https://github.com/QwenLM/Qwen-Image-2.1/blob/main/LICENSE)

## 3. 🔥 Cactus `Needle 3` — 8～29MB급 모델로 Tool Calling을 스마트폰·웨어러블까지

![Cactus Needle](https://aitoolly.com/_next/image?q=75&url=https%3A%2F%2Fopengraph.githubassets.com%2F1%2Fcactus-compute%2Fneedle&w=3840)

### 핵심 요약

Cactus Compute가 공개한 Apache 2.0 프로젝트 `Needle 3`가 빠르게 주목받고 있다. 확인 시점 GitHub는 약 **11.9K Stars** 규모다. Needle 3는 Chatbot이 아니라 **Tool Calling·Structured Extraction·Classification을 작은 기기에서 처리하기 위한 Automation Foundation Model**이다.

전체 구조는 29～121M Parameter의 `Laddered Simple Attention Network`다. 하나의 Weight Set 안에서 **2～20 Layer 깊이를 각각 독립적인 배포 Model처럼 선택**할 수 있다. Cactus는 이를 `Intelligence Ladder`라고 부른다. CQ2 Quantization과 `.cact` 포맷을 사용해 Deployment Binary를 약 8～29MB급으로 줄였고, Native Engine은 1MB 미만으로 13개 Platform에 제공한다.

Tool Schema로부터 Byte-level Grammar를 생성해 JSON Output Shape를 강제하고, Tool Argument는 User Request에서 근거를 찾을 수 있는 값으로 제한하는 Grounding Gate도 둔다. 즉 작은 모델이 자유롭게 문장을 생성하도록 하기보다 **좁은 행동 공간 안에서 정확히 결정하도록 설계**했다.

### 왜 중요한지

Agent Architecture가 모든 요청을 Cloud Frontier LLM에 보내는 방식에서 벗어나고 있다. 조명 제어, 알림 분류, 스마트폰 Intent, 간단한 Sensor Action처럼 선택지가 명확한 작업은 **수십 MB짜리 Local Model이 훨씬 싸고 빠르며 Privacy 측면에서도 유리**하다.

Needle 3가 보여주는 방향은 명확하다.

> 큰 모델은 계획하고, 작은 모델은 현장에서 행동한다.

Agent 시대의 Edge AI가 `작은 Chatbot`이 아니라 **Local Action Router**로 자리 잡을 가능성을 보여주는 사례다.

Sources: [Needle 3 공식 페이지](https://www.cactuscompute.com/needle) · [Cactus Engineering Blog](https://www.cactuscompute.com/blog) · [GitHub](https://github.com/cactus-compute/needle)

## 4. Qwen `Qwen3.8-LiveTranslate` — 60개 언어를 들으며 동시에 통역

![Qwen LiveTranslate](https://qianwen-res.oss-accelerate.aliyuncs.com/Qwen3.5-LiveTranslate/model_arch_v3.png)

### 핵심 요약

Alibaba가 `qwen3.8-livetranslate-flash-realtime`을 공개했다. 실시간 Audio와 선택적 Image Context를 받아 **번역 Text와 Speech를 Streaming Output**하며, 60개 언어를 이해하고 29개 언어로 Speech Output을 제공한다. Alibaba Cloud 공식 문서 기준 Context Window는 53,248 Token이다.

이번 세대는 통역 지연을 줄이기 위해 입력을 다 들은 뒤 번역하는 방식보다 **듣는 과정과 생성 과정을 더 촘촘하게 Interleave**한다. Qwen 측 공개 내용을 바탕으로 한 보도에서는 Length-Adaptive Average Lagging이 이전 2.8초에서 약 **2.3초**로 줄었다고 전했다. Speaker Diarization과 Source·Translation 동시 표시도 추가됐다.

### 왜 중요한지

실시간 통역에서 가장 어려운 문제는 번역 정확도만이 아니다. 문장이 끝날 때까지 기다리면 정확하지만 대화가 답답해지고, 너무 빨리 번역하면 뒤에서 나온 Context 때문에 의미를 다시 고쳐야 한다.

따라서 이 분야의 핵심 경쟁력은 **Accuracy × Latency × Voice Continuity × Speaker Tracking**의 균형이다. 60개 언어를 Streaming Audio Agent에 직접 연결할 수 있게 되면 국제회의, 고객센터, 여행, 교육, Remote Collaboration에서 Voice Agent의 사용범위가 크게 넓어진다.

Sources: [Alibaba Cloud 공식 문서](https://www.alibabacloud.com/help/en/model-studio/qwen3-8-livetranslate-flash-realtime) · [QwenCloud 모델 페이지](https://www.qwencloud.com/models/qwen3.8-livetranslate-flash-realtime)

## 5. Naive AI, 제품도 나오기 전에 `$400M` 조달 — `Pretraining보다 Post-training`에 거는 베팅

### 핵심 요약

The Information에 따르면 Tsinghua University 교수 **Jifeng Dai**가 2026년 2월 설립한 Beijing 기반 `Naive AI`가 Tencent, IDG Capital, MPCi, HSG 등으로부터 세 차례에 걸쳐 총 **$400M**을 조달했고, 최근 Round에서 Post-money Valuation **$1.42B**를 인정받았다. 회사 인원은 아직 100명 미만이며 첫 제품도 공개되지 않았다.

더 흥미로운 것은 기술 전략이다. Naive AI는 Frontier Model을 처음부터 Pretraining하는 대신 **기존 중국 Open-weight Model을 Base로 구조를 수정하고 Mid-training·Post-training·Reinforcement Learning을 집중적으로 적용**하는 것으로 전해졌다. 첫 모델 `Naive`는 이르면 9월 안에 Open Weight로 공개할 계획이다. 회사는 Recursive Self-Improvement도 연구하고 있다.

이 투자규모와 개발 계획은 The Information이 익명 관계자를 인용해 보도한 것이며, 회사가 상세 수치를 공식 발표한 것은 아니다.

### 왜 중요한지

지금까지 Frontier AI 회사의 핵심 경쟁력은 거대한 Pretraining Cluster를 감당할 자본과 데이터였다. Naive AI는 다른 질문을 던진다.

> 이미 좋은 Open Weight가 넘쳐난다면 굳이 처음부터 다시 학습해야 하는가?

Base Model을 가져오고 **Post-training Data, RL, Tool Use, Domain Workflow, Evaluation Loop**에 자본을 집중해도 강한 모델을 만들 수 있다면 신규 AI Lab의 비용 구조가 크게 바뀐다. 앞으로 Model 산업의 경쟁력이 `누가 가장 큰 Pretraining을 했는가`에서 **누가 기존 Foundation을 가장 잘 재가공하고 특화시키는가**로 일부 이동할 수 있다.

Source: [The Information — A Tsinghua Professor’s Stealth LLM Startup Hits $1.4 Billion Valuation](https://www.theinformation.com/articles/tsinghua-professors-stealth-llm-startup-hits-1-4-billion-valuation)

## 이번 회차의 핵심

이번 다섯 소식은 서로 다른 영역에서 같은 변화를 보여준다.

- **Step 5 Preview** → Frontier Model을 Long-horizon Agent Work 중심으로 설계
- **Qwen-Image-2.1** → 생성 모델을 편집 가능한 Production Asset 도구로 확장
- **Needle 3** → Agent Action을 수십 MB급 Local Model로 내려보냄
- **Qwen3.8-LiveTranslate** → Voice Agent의 언어 장벽과 Latency를 동시에 낮춤
- **Naive AI** → Pretraining보다 Post-training과 Refinement에 대규모 자본을 투입

결국 AI Stack은 하나의 초거대 모델이 모든 일을 하는 방향보다

> **Frontier Planner → Specialist Model → Local Decision Model → Runtime → Post-training Loop**

처럼 역할별로 분화되고 있다. 앞으로 모델 경쟁에서 중요한 질문은 `Parameter가 얼마나 큰가`만이 아니라 **어떤 역할을 어느 크기의 모델에 맡기고, 그 모델을 어떤 데이터와 Feedback Loop로 계속 개선할 것인가**가 될 가능성이 크다.
