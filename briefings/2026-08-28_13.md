## 1. 미 법원, Pentagon의 Anthropic 블랙리스트 조치 차단

**핵심 요약:** 미국 연방법원은 8월 28일 Pentagon이 Anthropic을 국가안보 공급망 위험으로 지정한 조치를 차단했다. 분쟁은 Anthropic이 Claude를 미국 내 감시나 완전자율 무기에 사용하는 데 제한을 두면서 시작됐으며, Rita Lin 판사는 Pentagon 조치가 불법적이고 근거가 부족하다고 판단했다. Anthropic은 관련 조치가 보복적이며 수정헌법 제1조와 제5조 권리를 침해한다고 주장해 왔다.

**왜 중요한지:** 이 사건은 AI 모델 공급사의 안전 정책과 정부의 군사·정보 활용 요구가 충돌할 때 누가 사용 범위를 결정하는지에 대한 중요한 선례가 될 수 있다. Frontier AI 기업의 정책이 단순한 서비스 약관이 아니라 정부 조달과 국가안보 정책에 직접 영향을 주는 단계에 들어갔다는 의미다.

## 2. Claude Code v2.1.248 — Restricted mode와 세션 간 메시징 추가

**핵심 요약:** Anthropic은 8월 27일 Claude Code v2.1.248을 공개했다. 새 `--restricted` 모드는 명령·코드 실행 도구와 WebFetch를 기본 제거하고, 파일 도구를 작업 디렉터리 안으로 제한하며 `bypassPermissions`도 거부한다. 같은 머신의 서로 다른 세션 사이에서 `SendMessage`와 `ListAgents`를 이용한 메시징도 추가됐다. 장시간 세션의 prompt-cache miss를 수정했고 Workflow 도구 설명의 prompt footprint도 약 5.7k tokens에서 약 1k tokens로 줄였다. `prod.env`, `*.tfvars`, 임시 키 파일 등이 cloud session에 잘못 업로드될 수 있던 문제도 수정했다.

**왜 중요한지:** Coding Agent가 장기 실행·병렬 실행되는 방향으로 가면서 핵심 경쟁력이 모델 성능만이 아니라 권한 격리, 세션 간 협업, prompt caching, credential 보호로 이동하고 있다. 특히 Restricted mode는 Agent를 CI나 기업 환경에 넣을 때 필요한 최소권한 실행 모델에 가깝다.

Sources:
- https://github.com/anthropics/claude-code/releases/tag/v2.1.248

## 3. Hermes Agent v0.20.6 — 브라우저·MCP·캐시·보안 기능 대규모 통합

**핵심 요약:** Nous Research는 8월 27일 Hermes Agent v0.20.6을 공개했다. v0.20.5 이후 약 525개 PR, 1,313 commits를 묶은 release다. 사용자 동의를 전제로 기본 Chromium profile을 활용하는 real-profile browsing, 별도 OS browser window, SSH remote-update engine, 50개 이상의 검증된 remote MCP server catalog, `web_search`·`web_extract` TTL caching, lean-tail compression 기본화, multi-query tool search, OS keychain 기반 secret encryption 등이 포함됐다. Model picker에는 GLM-5.3-Flash, MiniMax M3 free, MiniMax H3 Max video도 추가됐다.

**왜 중요한지:** 범용 Agent의 차별화가 단순 모델 호출에서 실제 브라우저 상태, 원격 장비, MCP 서비스, secret 관리, context 압축 같은 runtime 영역으로 빠르게 이동하고 있음을 보여준다. 특히 검색 결과 캐싱과 lean-tail compression은 장시간 Agent의 비용과 context 소비를 줄이는 실무적인 변화다.

Sources:
- https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.27

## 4. Z.ai GLM-5.3-Flash — 320B 중 18B만 활성화하는 오픈 멀티모달 모델

**핵심 요약:** Z.ai는 GLM-5 계열 첫 native multimodal model인 GLM-5.3-Flash를 공개했다. 총 320B parameters 중 18B만 활성화하는 구조이며 sparse attention과 linear attention을 결합한 hybrid architecture, mHC, 30T-token multimodal pretraining을 사용한다. Z.ai는 GLM-5.2보다 낮은 비용으로 coding·agentic benchmark에서 큰 향상을 주장한다. BF16 weights가 Hugging Face에 공개됐고 vLLM, SGLang, Transformers, KTransformers, Unsloth 등으로 직접 serving할 수 있다.

**왜 중요한지:** Frontier급 Agent 성능을 지향하는 모델이 API 전용이 아니라 직접 배포 가능한 open weights 형태로 제공된다는 점이 핵심이다. Active parameter가 18B라는 설계는 대형 MoE 계열에서 추론 비용을 줄이려는 흐름을 잘 보여준다. 공개 weight와 다양한 serving framework 지원은 자체 LLM Gateway나 Agent infrastructure를 운영하는 팀에게 선택지를 넓힌다.

Sources:
- https://z.ai/blog/glm-5.3-flash
- https://huggingface.co/zai-org/GLM-5.3-Flash-BF16

## 5. GitHub Trending `claude-mem` — Agent 메모리를 별도 계층으로 분리

**핵심 요약:** `thedotmack/claude-mem`이 현재 GitHub Trending에 올라 있다. Agent의 tool usage를 자동 수집하고 semantic summary로 압축한 뒤 다음 session에 관련 context를 다시 주입하는 persistent memory system이다. Progressive disclosure, skill-based search, privacy tags, Web Viewer를 제공하며 Claude Code뿐 아니라 OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode 등 여러 Agent와의 연동을 지향한다. 내부적으로 lifecycle hooks, worker service, SQLite, vector search와 단계적 retrieval 구조를 사용한다.

**왜 중요한지:** Agent가 오래 일할수록 전체 과거 대화를 매번 prompt에 넣는 방식은 비용과 context window 모두에서 비효율적이다. `claude-mem` 같은 프로젝트는 memory를 모델 내부 기능이 아니라 독립된 retrieval·compression infrastructure로 다루려는 흐름을 보여준다. 앞으로 Agent stack에서 Memory가 MCP나 Skills처럼 독립적인 표준 계층으로 발전할 가능성을 보여주는 사례다.

Sources:
- https://github.com/thedotmack/claude-mem
- https://github.com/trending

## 이번 회차의 핵심

이번 회차에서 가장 실무적으로 중요한 변화는 Claude Code의 Restricted mode와 Hermes의 context·cache·secret 관리 개선이다. Agent가 장기 실행되고 여러 도구를 쓰기 시작하면서 경쟁의 중심이 `Model → Runtime → Permissions → Memory → Skills`로 빠르게 이동하고 있다. 동시에 GLM-5.3-Flash처럼 공개 weight를 가진 효율형 대형 모델이 등장하면서 Agent runtime과 model을 독립적으로 조합하는 구조가 더 현실적인 선택지가 되고 있다.
