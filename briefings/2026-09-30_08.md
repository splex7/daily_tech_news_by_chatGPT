# AI·LLM·에이전트 최신 브리핑

**2026년 9월 30일 08시 KST**

직전 9월 29일 20시 브리핑의 Shopify WebMCP Checkout, JEV-27B, GitHub Security Lab Android Agent, OpenRig, Anthropic IPO는 중대한 후속이 없어 제외했다. 이번 회차의 핵심은 **고성능 모델의 비용 효율, 상시 가동 Agent, 표 데이터용 Foundation Model, 오픈웨이트 모델의 사이버 역량, SMB·Enterprise Agent 경쟁**이다.

## 1. OpenAI `GPT-6.1 Sol` — Astra급 Agent 성능을 5분의 1 가격대로

**핵심 요약:** OpenAI가 9월 29일 DevDay에서 `GPT-6.1 Sol`을 공개했다. OpenAI는 Agentic Coding, Computer Use, Professional Work에서 GPT-6 Astra에 근접하면서 표준 입력·출력 Token 가격은 Astra의 약 5분의 1이라고 설명한다. API 가격은 100만 Token당 입력 $2, Cached Input $0.10, 출력 $10이다. GPT-6.1 Sol은 API와 ChatGPT Work, Codex에 제공되며 GitHub Copilot에도 배포가 시작됐다.

OpenAI 자체 평가에서는 DeepSWE 1.1에서 Astra와 비슷한 수준을 약 5분의 1 Task Cost로 달성했고, OSWorld 2.0에서는 GPT-6 Sol보다 7%p 높으면서 Astra와 2.1%p 차이까지 접근했다고 발표했다. Terminal-Bench Science의 최대 추론 설정에서는 평균 Task Cost가 $5.47로, Opus 5.5와 Astra의 약 $23 수준보다 낮았다. 공급사 자체 Benchmark라는 점은 구분해서 볼 필요가 있다.

**왜 중요한가:** 이제 모델 가격을 `$/Token`만으로 비교하기 어렵다. 실제 Agent 비용은 추론 Step, Tool Call, 재시도 횟수까지 포함한 **Cost per Task**로 결정된다. GPT-6.1 Sol은 Frontier급 성능이 빠르게 더 낮은 비용 계층으로 내려오고 있음을 보여준다. Agent를 대량 운영하는 기업에서는 최고 모델 한 번보다 "충분히 강한 모델을 훨씬 많이 호출하는 구조"가 더 경제적일 수 있다.

## 2. OpenAI `Dots + Decisions API` — 24시간 Agent와 초고속 판단 계층을 한 스택으로

**핵심 요약:** OpenAI가 `Dots`라는 always-on Agent를 공개했다. GPT-6 Astra 기반이며 각 Dot은 자체 Cloud Computer를 가지고 24시간 목표를 수행한다. ChatGPT, Slack, Teams, Voice를 통해 접근할 수 있고 4,000개 이상의 앱과 Plugin으로 연결된다. 사용자는 Agent가 자동으로 해도 되는 일, 승인이 필요한 일, 절대 해서는 안 되는 일을 경계로 설정할 수 있다.

개발자 쪽에서는 동시에 `Decisions API`와 Computer Use가 포함된 `Agents API`를 발표했다. Decisions API는 Luna의 지능을 유한한 선택지 문제에 집중시켜 분류, Routing, 다음 Agent Action 선택 같은 결정을 빠르게 수행한다. Agents API는 Computer Use, Codex Multi-Agent, Tool Search·Calling, Context Compaction을 OpenAI 호스팅 인프라에서 제공한다.

**왜 중요한가:** 하나의 거대한 LLM이 모든 Step을 처리하는 구조보다 **Persistent Agent + 빠른 Decision Layer + Tool Runtime**으로 역할이 분리되고 있다. 특히 Decisions API는 최근 Jev, CLM, Julia, Intern-Decision처럼 빠른 System One 판단 계층이 독립적인 제품 범주로 자리 잡고 있다는 흐름을 OpenAI가 직접 API로 공식화했다는 의미가 있다.

## 3. 🔥 NVIDIA `Kumo Tabular` — 표 데이터도 LLM처럼 Training 없이 예측

**핵심 요약:** NVIDIA가 9월 29일 `Kumo Tabular`을 공개했다. Label이 있는 표의 일부 행을 Context로 주면 별도 Training, Tuning, Feature Engineering 없이 한 번의 Forward Pass로 새 행의 Classification 또는 Regression 결과를 예측한다. 모델은 28M～215M Parameter의 세 가지 크기로 제공되고, 학습에는 실제 고객 데이터가 아닌 합성 표 데이터만 사용됐다.

Model Weight는 OpenMDW-1.1로 공개됐고, 추론 Library `structured-data-models`는 GitHub에서 오픈소스로 제공된다. NVIDIA 자체 평가에서는 TabArena, BeyondArena, TALENT, ScoringBench 네 Benchmark에서 1위를 기록했으며, 단일 RTX 6000 Pro 환경에서 LimiX-2보다 17배 빠르다고 발표했다.

**왜 중요한가:** 기업 AI의 실제 데이터 대부분은 문서보다 **Table**에 있다. 고객 이탈, 부도 위험, 수요 예측, 가격, 거래 데이터처럼 지금까지 Gradient Boosting과 AutoML이 맡던 영역에 Foundation Model 방식이 들어오고 있다. 매번 모델을 새로 학습하는 대신 몇 개의 Labelled Row를 Context로 넣어 바로 예측한다면 Enterprise ML Workflow 자체가 단순해질 수 있다.

- NVIDIA/Hugging Face 공식 소개: https://huggingface.co/blog/nvidia/kumo-tabular
- Model Weight: https://huggingface.co/nvidia/Kumo-Tabular
- GitHub: https://github.com/NVIDIA/structured-data-models

## 4. ⚠️ `GLM-5.3` — NIST가 가장 강력한 오픈웨이트 사이버 모델로 평가

**핵심 요약:** Anthropic이 9월 29일 Z.ai의 오픈웨이트 `GLM-5.3`에 대한 사이버 역량 분석을 공개했다. Anthropic의 격리된 테스트에서는 GLM-5.3이 알려진 취약점뿐 아니라 복합적인 Exploit 개발까지 수행할 수 있었고, 자체 Safeguard가 특정 조건에서 64%～100% 우회될 수 있었다고 보고했다. 이 우회율은 Anthropic 자체 실험 결과다.

보다 독립적인 NIST CAISI 평가에서는 GLM-5.3을 **현재까지 공개된 가장 사이버 역량이 높은 오픈웨이트 모델**로 평가했다. 다만 종합 사이버 Benchmark에서는 미국 Frontier 모델보다 약 4개월 뒤처진 수준이라고 분석했다. 즉 "세계에서 가장 강한 사이버 모델"이라는 뜻은 아니지만, 누구나 Weight를 내려받아 실행할 수 있는 모델의 Capability가 중요한 임계점에 가까워지고 있다는 의미다.

**왜 중요한가:** 오픈웨이트의 장점은 Local Deployment, 연구 자유도, 비용 절감이지만, Weight가 공개되면 API 수준의 거부 정책을 강제하기 어렵다. 앞으로 모델 Release 논쟁은 단순히 Open vs Closed가 아니라 **Capability 수준 × Weight 공개 여부 × Runtime Safeguard**의 조합으로 봐야 한다. 동시에 방어자에게도 취약점 탐색과 Patch 자동화 능력을 크게 높여주는 양면성이 있다.

- Anthropic 분석: https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities
- NIST CAISI 평가: https://www.nist.gov/news-events/news/2026/09/caisis-assessment-zais-glm-53-cyber-capabilities

## 5. Meta `Muse for Small Business` — 개인 Agent에서 SMB·Enterprise 운영 플랫폼으로

**핵심 요약:** Meta가 9월 29일 `Muse for Small Business`를 발표했다. 기존 Muse에 Asana, Box, Canva, Dropbox, Figma, QuickBooks, Klaviyo, Notion, Shopify, Slack, Stripe, Zoom 등과 Facebook·Instagram Business Account를 연결할 수 있게 했다. Muse는 매출·광고·SNS·재무 데이터를 분석하고 Growth Plan, Campaign Draft, Email Draft, 이상 비용 탐지 같은 업무를 수행한다. Publishing, Sending, Spending은 사용자 승인 없이는 실행하지 않도록 설계됐다.

하루 전 Meta는 별도로 `Meta Enterprise Platform`을 공개했다. Muse, Meta Business Agent, Muse API, Muse Code를 기업용 Full Stack으로 묶고, MongoDB CEO였던 CJ Desai를 Chief Enterprise Platform Officer로 영입했다. 따라서 이번 발표는 이전의 개인용 Muse 기기 확장과 달리 **기업 운영 및 수익화 전략으로의 본격적인 전환**이라는 점에서 중대한 후속 업데이트다.

**왜 중요한가:** Agent 경쟁은 이제 개인 Assistant를 넘어 **업무 데이터와 실행 권한을 누가 연결하느냐**의 경쟁으로 이동하고 있다. SMB는 ERP나 복잡한 Automation Team이 없는 경우가 많아, 여러 SaaS를 연결해 자연어로 운영하는 Agent의 효과가 특히 클 수 있다. Meta가 광고 중심 회사에서 Enterprise AI Platform 사업자로 확장하려는 전략적 변화도 주목할 부분이다.

- Meta Enterprise Platform 공식 발표: https://about.fb.com/news/2026/09/launching-meta-enterprise-platform/
