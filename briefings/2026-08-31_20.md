# AI·LLM·에이전트 최신 브리핑

**2026-08-31 20:00 KST**

이전 회차에서 다룬 Codex Persistent mode, Cursor 모델 공급 이슈, NVIDIA OO Agents, Diffusion Studio, Caterpillar 사례 등은 제외했다. 이번 회차는 신규 오픈웨이트 모델, Agent Harness, GitHub 급상승 Skill, 유럽 AI 인프라 투자에 초점을 맞췄다.

## 1. Z.ai `GLM-5.3-Flash` — 320B MoE, 18B 활성, 1M 컨텍스트의 오픈웨이트 모델

### 핵심 요약
Z.ai가 8월 26일 `GLM-5.3-Flash`를 공개했다. 320B 전체 파라미터 중 토큰당 18B를 활성화하는 MoE 구조이며 텍스트·이미지·비디오를 입력으로 받고 최대 1M 토큰 컨텍스트를 지원한다. 모델 가중치는 MIT License로 공개됐다. 출시 전에는 `Ox Alpha`라는 익명 모델로 OpenRouter와 OpenCode에서 실전 테스트됐다.

### 왜 중요한지
최근 오픈 모델 경쟁은 단순 파라미터 규모가 아니라 `작은 활성 파라미터 + 긴 컨텍스트 + 멀티모달 + 낮은 추론비용` 조합으로 이동하고 있다. 특히 Agent와 Coding workload에서 강한 오픈웨이트 모델이 늘어나면 기업이 특정 API 업체에 종속되지 않고 자체 Agent Stack을 구성하기 쉬워진다.

Sources:
- https://z.ai/blog/glm-5.3-flash
- https://www.businessinsider.com/ox-alpha-model-made-by-china-z-ai-2026-8

## 2. DeepSeek `DeepSeek Harness` 공개 — Agent의 모든 구성요소를 Plugin으로 교체

### 핵심 요약
DeepSeek가 오픈소스 Agent Harness `dsh`의 Developer Preview를 공개했다. 모델, 도구, Skill, Session, Sandbox, Storage, Agent Loop, Scheduler, UI까지 모두 Plugin 형태로 구성된다. 기반에는 Plugin 로딩과 의존성 관리만 담당하는 `Cordis` 커널이 있다.

### 왜 중요한지
Agent 제품의 핵심 경쟁력이 LLM 자체에서 Harness 구조로 이동하고 있다는 강한 신호다. 모델이나 Tool을 고정하지 않고 구성요소를 갈아 끼울 수 있으면 기업은 Agent Runtime은 유지하면서 OpenAI, Anthropic, DeepSeek, Local Model 등을 자유롭게 교체할 수 있다.

Sources:
- https://www.deepseek.com/harness/en/
- https://github.com/deepseek-ai/deepseek-harness

## 3. GitHub 급상승 `scientific-agent-skills` — 과학자의 업무 노하우가 SKILL.md로 패키징

### 핵심 요약
K-Dense의 `scientific-agent-skills`가 8월 31일 GitHub Trending 상위권에 올랐다. 약 40.1K Stars 규모이며 이날 1,100개 이상 Star가 추가됐다. 현재 저장소에는 160개 이상의 연구·과학 Skill과 100개 이상의 과학·금융 데이터베이스 접근 워크플로우가 포함돼 있다. Claude Code, Codex, Gemini CLI, Cursor, Hermes 등 여러 Agent Host에서 사용할 수 있다.

### 왜 중요한지
AI 시대의 전문성은 Prompt보다 `재사용 가능한 업무 절차` 형태로 유통되기 시작하고 있다. 논문 검색, 약물 분석, 유전체 처리, 시계열 분석 같은 고도의 분야 지식이 `SKILL.md + 코드 + 참고자료`로 저장되면 조직의 경험 자체가 Agent에게 설치 가능한 자산이 된다.

Sources:
- https://github.com/K-Dense-AI/scientific-agent-skills
- https://github.com/trending

## 4. GitHub 급상승 `Archify` — 자연어와 코드베이스를 검증 가능한 시스템 다이어그램으로

### 핵심 요약
`tt-a1i/archify`가 8월 31일 GitHub Trending에서 빠르게 상승했다. 약 35.7K Stars 규모이며 아키텍처, Workflow, Sequence, Data Flow, Lifecycle 다이어그램을 Agent가 생성할 수 있는 Skill이다. 단순 SVG 생성이 아니라 Typed JSON IR을 만든 뒤 Schema·Layout·Route 등을 검증하고 HTML, PNG, SVG, WebM 등으로 내보낸다.

### 왜 중요한지
Agent가 문서나 그림을 단순 생성하는 것을 넘어 `검증 가능한 구조화 산출물`을 만드는 방향을 보여준다. 특히 코드베이스를 읽고 실제 구조와 연결된 Architecture Diagram을 생성할 수 있다는 점에서 Software Documentation과 Design Review 자동화에 직접 연결된다.

Sources:
- https://github.com/tt-a1i/archify
- https://tt-a1i.github.io/archify/
- https://github.com/trending

## 5. 유럽 `LUMI-AI`에 약 €388M 투자 — AI 경쟁이 모델에서 국가 Compute 인프라로 확대

### 핵심 요약
Reuters는 8월 31일 EuroHPC와 북유럽·중부 유럽 국가 컨소시엄이 프랑스 Bull과 약 €387.8M 규모의 `LUMI-AI` 슈퍼컴퓨터 계약을 체결했다고 보도했다. 시스템은 핀란드에 구축되며 AMD 칩, IBM Storage, Nokia Networking을 사용하고 2027년 하반기 가동을 목표로 한다. EU는 이미 19개 AI Factory와 12개 슈퍼컴퓨터 네트워크를 구축하고 있다.

### 왜 중요한지
AI 산업의 경쟁력은 모델 연구만으로 확보되지 않는다. 국가와 기업이 직접 접근할 수 있는 Compute, Storage, Network, 데이터센터가 장기적인 AI 경쟁력의 기반이 되고 있다. 미국·중국 중심의 Hyperscaler 경쟁에 대응해 유럽이 `Sovereign Compute`를 산업 정책으로 구축하고 있다는 점이 중요하다.

Source:
- https://www.reuters.com/world/europe/europe-expands-ai-computing-network-with-390-million-order-frances-bull-2026-08-31/

## 이번 회차 핵심 흐름

이번 회차에서 가장 중요한 변화는 `Model → Harness → Skill → 검증 가능한 산출물 → Compute Infrastructure`로 AI Stack이 빠르게 분화하고 있다는 점이다.

GLM-5.3-Flash는 모델 계층의 비용 효율화를, DeepSeek Harness는 Agent Runtime의 모듈화를, Scientific Agent Skills와 Archify는 전문 업무 지식의 패키징을, LUMI-AI는 이를 실행할 국가 단위 Compute 경쟁을 보여준다.

> AI 경쟁의 중심이 더 좋은 Prompt를 만드는 것에서, 모델·Harness·Skill·데이터·Compute를 자기 조직에 맞게 조합하고 축적하는 능력으로 이동하고 있다.
