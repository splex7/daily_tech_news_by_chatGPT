## 1. Tencent `WeVisDoc-2B/4B` 공개 — 작은 오픈 VLM이 문서 이미지를 Markdown·LaTeX·HTML로 직행

![WeVisDoc benchmark](https://huggingface.co/tencent/WeVisDoc-4B/resolve/main/assets/figure1.png)

### 핵심 요약
Tencent가 `WeVisDoc-2B`와 `WeVisDoc-4B`를 공개했다. Qwen3-VL-2B/4B-Instruct를 기반으로 한 end-to-end 문서 파서로, 페이지 이미지를 읽어 자연어 텍스트뿐 아니라 **Markdown, LaTeX 수식, HTML 표**까지 한 번에 구조화해 출력한다. 두 모델 모두 Apache 2.0 라이선스로 공개됐다.

Tencent의 자체 평가에서 WeVisDoc-4B는 OmniDocBench v1.6 Overall **95.38**, PureDocBench 3개 트랙 평균 **75.54**를 기록했다. 공개 비교표의 end-to-end 문서 파서 가운데 네 설정 모두 1위라고 보고했으며, 결과는 출시사 측 평가이므로 독립 재현과는 구분해서 볼 필요가 있다.

### 왜 중요한지
문서 AI는 오랫동안 `OCR → Layout 분석 → Table/Formula 복원 → 후처리`의 여러 단계를 조합했다. WeVisDoc처럼 2B～4B급 VLM이 페이지에서 곧바로 구조화 Markdown을 생성하면 **RAG 전처리, PDF 데이터 추출, 사내 문서 자동화**의 파이프라인을 단순화할 수 있다.

특히 거대한 범용 VLM 대신 작은 전문 모델을 로컬이나 자체 GPU에 배치할 수 있다는 점에서 `범용 Frontier Model + 소형 전문모델` 분화가 더 뚜렷해지고 있다.

- Model: https://huggingface.co/tencent/WeVisDoc-4B
- Paper: https://arxiv.org/abs/2609.20423

## 2. 🔥 DeepSeek `deepseek-harness` — 22만 Stars를 넘긴 오픈소스 Agent Runtime, 핵심은 “Everything is a Plugin”

![DeepSeek](https://avatars.githubusercontent.com/u/148330874?v=4)

### 핵심 요약
DeepSeek의 MIT 오픈소스 `deepseek-harness`, 명령어 `dsh`가 GitHub에서 급격히 확산되고 있다. 9월 18일 확인 시점 약 **228K Stars, 27K Forks** 규모다. 아직 Developer Preview이며 호환성을 깨는 변경이 계속될 수 있다고 프로젝트가 명시한다.

핵심 설계는 **Everything is a Plugin**이다. Model Adapter, Tool Registry, Session Log, Agent Loop까지 모두 Cordis 기반 Plugin으로 구성돼 설정만으로 교체할 수 있다. 기본 Bundle에는 Persistence, Sandbox, Approval Policy, Credentials, Telemetry가 포함되고, Background Job과 Webhook Session, Experimental Agent Teams의 durable roster·task board·mailbox도 제공한다.

### 왜 중요한지
DeepSeek의 오픈 전략이 이제 모델 Weight나 CUDA Kernel을 넘어 **Agent를 실제로 운영하는 Harness 계층**까지 확장되고 있다.

Agent 시대에는 같은 모델을 사용해도 Context 관리, Tool 실행, Sandbox, 승인정책, Background Work, Subagent Orchestration에 따라 실제 성능과 안정성이 크게 달라진다. `deepseek-harness`는 이 계층을 하나의 교체 가능한 플랫폼으로 만들려는 시도다.

즉 오픈 AI Stack이 점점

`Open Weight → Inference Runtime → Agent Harness → Plugin Ecosystem`

으로 넓어지고 있다.

- GitHub: https://github.com/deepseek-ai/deepseek-harness
- Docs: https://deepseek-harness.github.io/deepseek-harness/

## 3. `LocalAI v4.10.0` — 로컬 LLM 실행기에서 프라이빗 AI Fleet 운영 플랫폼으로

![LocalAI fleet dashboard](https://github.com/user-attachments/assets/14311767-9b0e-4c32-82a4-421c76d0f406)

### 핵심 요약
약 **49K Stars**의 오픈소스 AI Runtime LocalAI가 9월 18일 KST 기준 `v4.10.0`을 공개했다. 이번 릴리스는 28일 동안 280개 PR을 반영했고, 단일 머신 실행보다 **여러 AI Node를 운영하는 Fleet 관리**에 큰 비중을 둔다.

새 Fleet Dashboard에서는 Cluster Health, VRAM·RAM·CPU·Disk Capacity, Running Model Replica, in-flight Request를 한눈에 보고 여러 Node를 Drain·Resume·Remove할 수 있다. `credentials.yaml`을 통해 OCI Registry, Model Gallery, HTTP/GitHub Download용 Secret을 중앙 관리하고, K8s Secret이 교체되면 재시작 없이 새 값을 읽을 수 있도록 했다. `local-ai benchmark` CLI도 추가돼 모델별 End-to-end Latency와 Tokens/sec를 비교할 수 있다. 이번 버전에는 4개 CVE 수정과 Distributed Mode 안정화도 포함됐다.

### 왜 중요한지
Local AI가 취미용 `내 PC에서 모델 한 개 실행` 단계를 넘어가고 있다.

기업이 Open Model을 자체 인프라에서 쓰려면 결국 필요한 것은 **Node Lifecycle, Capacity, Secret Rotation, Benchmarking, Distributed Serving, 보안패치**다. LocalAI가 이런 운영 기능을 흡수한다는 것은 프라이빗 AI에서도 Kubernetes와 비슷한 `운영면`이 중요해지고 있다는 신호다.

- Release: https://github.com/mudler/LocalAI/releases/tag/v4.10.0
- Project: https://github.com/mudler/LocalAI

## 4. Mantic, `$25M` 조달 — LLM의 다음 실전 벤치마크가 “미래 사건의 확률”로

> 관련 이미지와 원문: Reuters 보도 및 Mantic 공식 사이트

### 핵심 요약
런던의 AI Forecasting 스타트업 Mantic이 9월 18일 **$25M Seed Round**를 발표했다. Radical Ventures가 주도했고 Microsoft M12, Thinking Machines Lab, Balderton Capital 등이 참여했다.

Mantic은 다른 연구소의 Frontier Model을 기반으로 역사적 사건에서 예측을 반복 평가하고 개선해, 정치·경제·문화 같은 실제 미래 사건에 확률을 부여하는 시스템을 만든다. Reuters에 따르면 2026 Summer Metaculus Cup에서 모든 인간 참가자보다 높은 성적을 기록했고, 전체에서는 `laertes`라는 다른 Bot에 이어 두 번째였다. Metaculus의 AI Benchmark는 Human-in-the-loop를 허용하지 않고, 실제로 미래에 결과가 확정되는 문제로 Bot을 평가한다.

### 왜 중요한지
Forecasting은 일반 Benchmark와 달리 정답이 아직 존재하지 않는 상태에서 답해야 하므로 **학습 데이터 암기나 Benchmark Leakage의 영향이 훨씬 작다.**

따라서 `미래를 얼마나 정확한 확률로 예측하는가`는 투자, 공급망, 정책, 리스크 관리 같은 실제 의사결정에 바로 연결되는 Agent Capability가 될 수 있다. Mantic 사례는 Vertical AI의 가치가 텍스트 생성보다 **의사결정의 Calibration**에서 만들어질 수 있음을 보여준다.

- Reuters: https://www.reuters.com/technology/ai-startup-mantic-raises-25-million-superhuman-forecasting-2026-09-18/
- Mantic: https://www.mantic.com/
- Metaculus AI Forecasting Benchmark: https://www.metaculus.com/aib/2026/spring/

## 5. Anthropic, 실제 `Wet Lab` 구축 + Life Sciences Verification Program — AI Science가 물리 실험 Loop로

> 관련 이미지와 원문: Reuters 보도 및 Anthropic Science

### 핵심 요약
오늘 오전 브리핑에서는 Claude가 30개가 넘는 오픈소스 Biomolecular Model을 최적화한 사례를 다뤘다. 이후 공개된 중요한 후속 소식은 Anthropic이 샌프란시스코 Bay Area에 **실제 Wet Lab을 구축해 물리적 생물학 실험을 수행하고 있다는 것**이다. Anthropic 생명과학 책임자 Eric Kauderer-Abrams가 Reuters에 이를 확인했다.

Anthropic은 Claude가 향후 Lab Robot을 지시해 실험을 수행하는 방향을 탐색하고 있으며, 동시에 9월 17일 `Life Sciences Verification Program` Beta를 발표했다. 검증된 생명과학 조직에는 일반 모델보다 Biology 관련 제한을 조정한 Mythos·Opus·Sonnet 접근을 제공해 Drug Discovery, Research Biology, Clinical Development, Manufacturing 같은 전문 작업을 지원한다. Anthropic은 인간 감독이 필수라는 입장도 함께 강조하고 있다.

### 왜 중요한지
AI for Science의 이상적인 폐쇄형 Loop는

`가설 → 계산·모델링 → 실험 설계 → 로봇 실험 → 결과 데이터 → 다음 가설`

이다.

Morning 브리핑의 Software Optimization에서 불과 한 단계 더 나아가 **실제 물리 실험까지 Frontier AI 회사가 직접 연결하기 시작했다는 점**이 중요하다. Coding Agent가 Test를 실행하고 결과를 다시 읽듯, Science Agent도 현실의 실험 결과를 Feedback으로 받아 반복 개선하는 구조로 진화할 수 있다.

- Reuters: https://www.reuters.com/world/anthropic-quietly-sets-up-biology-lab-it-ramps-ai-drug-program-2026-09-18/
- Anthropic Science: https://www.anthropic.com/science
- Life Sciences Verification Program: https://www.anthropic.com/news/life-sciences-verification-program

## 이번 회차의 핵심

이번 다섯 소식을 연결하면 AI 산업의 중심이 `가장 큰 모델` 하나에서 **전문화·실행·운영·검증**으로 분화되고 있다.

- **WeVisDoc** → 2B～4B 전문모델이 복잡한 문서 Pipeline을 통째로 흡수
- **DeepSeek Harness** → Agent의 실행환경 자체가 오픈소스 Platform으로
- **LocalAI** → Local Model이 Fleet 단위 Enterprise Operation으로
- **Mantic** → 생성 품질보다 미래 예측의 확률 Calibration을 경쟁
- **Anthropic Wet Lab** → AI가 Software 밖의 물리 실험까지 Feedback Loop에 포함

핵심 흐름은 다음과 같다.

> **Specialized Model → Agent Harness → Private Fleet → Decision Calibration → Physical Experiment**

AI가 점점 더 좋은 문장을 쓰는 기술에서 벗어나 **특정 업무를 더 정확히 처리하고, 안정적으로 운영되며, 실제 결과를 측정해 다음 행동을 개선하는 시스템**으로 이동하고 있다.
