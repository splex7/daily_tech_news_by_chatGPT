## 1. Anthropic Claude Sonnet 5.5 — 일상 업무용 모델의 Agent 성능을 끌어올리다

**관련 이미지:** [Anthropic 공식 발표](https://www.anthropic.com/claude-sonnet-5-5)

### 핵심 요약
Anthropic은 2026년 9월 28일 Claude Sonnet 5.5를 공개했다. 회사는 Sonnet 5 대비 출력 속도가 30% 이상 빨라지고, 동일 작업 기준 비용은 최대 30% 낮아졌다고 설명한다. 가격은 입력 100만 Token당 $2, 출력 $10으로 Sonnet 5와 동일하다. Anthropic 자체 평가에서 Terminal-Bench 4.0은 70.6%를 기록했으며, GDPval-AA에서는 Opus 5.5와 2점 차이라고 밝혔다. 이런 수치는 공급사 자체 평가이므로 독립 Benchmark와는 구분해서 볼 필요가 있다.

### 왜 중요한지
Frontier Model 경쟁이 최고 성능 하나를 겨루는 단계에서, 실무에서 자주 호출할 수 있는 중간 가격대 모델의 Agent 성능과 Task Cost 경쟁으로 이동하고 있다. 대부분의 Coding, 문서 작성, Spreadsheet, Bug Fix를 Sonnet급 모델이 맡고 정말 어려운 작업만 Opus급으로 Escalation하는 구조가 더 현실적인 운영 패턴이 되고 있다.

## 2. NVIDIA Open Agent Safety Platform — Agent 보안을 모델 밖 Runtime 계층으로 이동

**관련 이미지:** [NVIDIA 공식 발표](https://nvidianews.nvidia.com/news/open-agent-safety-platform)

### 핵심 요약
NVIDIA는 9월 28일 Open Agent Safety Platform을 발표했다. 핵심은 오픈소스 Runtime인 OpenShell과 별도의 감시 계층인 Sentry다. OpenShell은 Agent의 파일 접근, 프로세스 실행, 외부 네트워크 요청을 실행 중에 정책으로 통제하며 Gateway, Supervisor, Sandbox 구조를 갖는다. NVIDIA는 Codex, Claude Code, Pi, Hermes 같은 Agent를 지원하고 Docker와 Kubernetes 환경에도 배포할 수 있다고 설명한다. Sentry는 BlueField-4 DPU를 활용해 Agent 행동을 별도 경로에서 감시하고 정책 경계를 벗어나면 격리하는 구조다.

### 왜 중요한지
최근 Agent 사고의 핵심은 모델이 나쁜 답을 하는 것이 아니라, 정상적인 목표를 수행하는 과정에서 파일·네트워크·SaaS 권한을 예상 밖으로 사용하는 데 있다. 따라서 기업용 Agent 보안은 Prompt Filter보다 Capability Control, Network Egress, Filesystem Policy, Audit 같은 Runtime 통제가 더 중요해지고 있다. Container 시대에 Kubernetes와 Sandbox가 필요했던 것처럼 Agent 시대에도 독립적인 실행·보안 계층이 생기는 흐름이다.

## 3. Oracle Fusion Claw — Enterprise Agent에 '운영 규칙'과 결정론적 계산을 결합

**관련 이미지:** [Oracle 공식 발표](https://www.oracle.com/news/announcement/oracle-extends-fusion-agentic-applications-with-introduction-of-fusion-claw-2026-09-29/)

### 핵심 요약
Oracle은 9월 29일 Fusion Claw를 공개했다. Fusion Claw는 Oracle Fusion Agentic Applications를 위한 Governed Agentic Execution Runtime으로, Frontier Model의 추론과 계획 능력에 결정론적 Enterprise Computation을 결합한다. Oracle은 Claw 기반 Agentic Application 25개를 새로 추가해 전체 포트폴리오를 75개로 확장했다고 밝혔다. 특히 Enterprise Operating Envelope로 목표, 표준 절차, 권한, Risk Threshold, 승인·Escalation 규칙을 정의하고, Outcome Trust Harness와 Outcome Receipt로 실행 정책과 Audit Trail을 관리한다.

### 왜 중요한지
기업용 Agent의 병목은 이제 답변 품질보다 '어떤 조건에서 무엇을 실행할 수 있는가'에 가깝다. Oracle의 접근은 LLM이 판단하되 금액 계산, 정책 적용, 승인 절차 같은 영역은 결정론적 시스템에 맡긴다. 즉 Enterprise Agent Architecture가 'LLM 하나가 모든 것을 한다'에서 Reasoning Model + Deterministic Compute + Policy Envelope + Audit로 분화되는 신호다.

## 4. Broadcom, Anthropic에 최대 $42B 금융 지원 — AI Chip 경쟁이 금융 구조까지 확장

**관련 이미지:** [Reuters 보도](https://www.reuters.com/business/broadcom-lend-anthropic-up-42-billion-lease-its-chips-filing-says-2026-10-01/)

### 핵심 요약
Reuters는 10월 1일 Anthropic의 IPO 관련 서류를 바탕으로 Broadcom이 Anthropic에 최대 $42B를 빌려줄 수 있는 금융 약정을 맺었다고 보도했다. 이는 단순한 대출이 아니라 Broadcom의 AI Compute·Chip Design 공급, 장비 Leasing, 인프라 Financing이 얽힌 구조다. Reuters에 따르면 이 금융 규모는 Anthropic이 2027년부터 사용할 TPU Compute Capacity에 대해 약정한 5년간 $125.2B Lease Commitment의 약 3분의 1에 해당할 수 있다. Broadcom은 Anthropic이 2027년 자사의 최대 Compute·Chip Design 고객이 될 것으로 예상하고 있다.

### 왜 중요한지
Frontier AI 경쟁의 자본 규모가 모델 학습비를 넘어 Chip 공급자와 Model Company가 서로의 수요와 자금을 동시에 보장하는 단계로 이동하고 있다. 이런 구조는 GPU·ASIC 공급망을 빠르게 키울 수 있지만, 공급자 금융과 장기 구매 약정이 결합되면서 실제 수요와 매출의 질을 평가하기 더 어려워질 수 있다. AI 인프라 경쟁이 기술뿐 아니라 금융 Engineering의 문제가 되고 있다는 뜻이다.

## 5. GitHub 급상승 Strata — 125B MoE를 일반 Gaming PC에서 로컬 실행

**관련 이미지·프로젝트:** [Niko1221/Strata GitHub](https://github.com/Niko1221/Strata)

### 핵심 요약
최근 공개된 MIT License 프로젝트 Strata가 10월 1일 GitHub 급상승 프로젝트 중 하나로 빠르게 확산되고 있다. Strata는 Qwen3.8-Flash-Next 125B MoE 모델을 NVIDIA GPU 12～24GB와 64GB RAM 수준의 일반 PC에서 실행하는 것을 목표로 하며 Windows와 Linux를 지원한다. 설치 후 Browser UI와 OpenAI-compatible API, Anthropic Messages API 형태의 Local Endpoint를 제공한다. 프로젝트 작성자가 공개한 RTX 5070 12GB + Ryzen 5 7600 + 64GB RAM 환경 측정에서는 저비트 Quantization에 따라 짧은 Chat 기준 수십 Token/s 수준을 제시하고 있다. 해당 성능 수치는 작성자 측 측정값이다.

### 왜 중요한지
대형 MoE 모델의 전체 Parameter 수가 커도 매 Token마다 활성화되는 Parameter와 KV Cache·Memory Offload를 최적화하면 Consumer Hardware에서 실용적인 Local Inference가 가능해지는 방향이 빨라지고 있다. Local API까지 OpenAI·Anthropic 호환 형태로 제공되면 기존 Agent나 Coding Tool의 Backend를 Cloud API에서 Local Model로 바꾸기도 쉬워진다. 비용, 데이터 주권, Offline Agent 측면에서 주목할 흐름이다.
