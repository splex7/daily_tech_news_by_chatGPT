## 2. Thomson Reuters 자체 LLM `Thomson` 출시

### 핵심 요약
Thomson Reuters가 법률, 세무, 규제 업무용 자체 모델 Thomson을 출시했다. 범용 프런티어 모델을 처음부터 만드는 대신 오픈소스 기반 모델을 자사 전문 데이터와 도메인 지식으로 특화하는 전략이다.

- Source: https://www.thomsonreuters.com/en/press-releases/2026/august/thomson-reuters-leverages-its-world-class-data-assets-to-launch-its-own-frontier-model

## 3. GitHub 화제 `andrej-karpathy-skills`

### 핵심 요약
`multica-ai/andrej-karpathy-skills`가 GitHub에서 크게 주목받았다. 거대한 프레임워크보다 LLM 코딩 실패 패턴을 정리한 Agent 행동 규칙에 가깝다. 핵심은 Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution이다.

### 왜 중요한가
코딩 에이전트 성능을 결정하는 요소가 Model에서 Model + System Prompt + Rules + Skills + Evaluation으로 이동하고 있음을 보여준다.

- GitHub: https://github.com/multica-ai/andrej-karpathy-skills

## 4. Physical AI 투자 가속, Generalist

### 핵심 요약
Google DeepMind와 Boston Dynamics 출신 인력이 만든 로보틱스 AI 스타트업 Generalist가 추가 대규모 투자를 유치했다. 짧은 영상 시연만으로 로봇이 새로운 작업을 학습하는 범용 로봇 모델을 지향한다.

### 왜 중요한가
LLM에서 검증된 foundation model 전략을 로봇에도 적용하려는 경쟁이 커지고 있다. 하나의 모델이 여러 종류의 로봇을 제어하는 Robot Foundation Model 시장이 형성될 가능성이 있다.

- TechCrunch: https://techcrunch.com/2026/08/25/robotics-startup-generalist-reaches-3b-valuation-sources-say/

## 5. Voice AI도 `Outcome Agent`로 이동

### 핵심 요약
Ringg AI가 추가 투자를 유치했다. 단순 상담전화 자동화에서 병원 예약, 장바구니 복구, 금융 KYC, 브라우저 업무 등 실제 업무 완료로 확장하고 있다.

- TechCrunch: https://techcrunch.com/2026/08/25/indias-ringg-gets-backing-from-peak-xv-as-it-pushes-voice-ai-past-the-phone-call/
