## 1. OpenAI, ‘자동화된 연구 인턴’ 목표 도달 — 연구 조직에서 사람 하루당 Agent 3.1일치 작업

![OpenAI researcher](https://d2xo500swnpgl1.cloudfront.net/uploads/oaiacademy/aidan-56360769-44c3-4fb6-a58b-aaabf058e47f-1765989090355.jpeg)

### 핵심 요약

OpenAI가 9월 6일 내부 연구 데이터를 공개하며, 지난해 제시했던 **2026년 9월까지의 ‘automated research intern’ 목표에 도달했다고 자체 평가**했다. OpenAI가 정의하는 연구 인턴은 사람의 지시 아래 잘 정의된 연구 과제를 수행하며, 숙련된 연구자가 며칠 걸릴 수 있는 작업까지 맡는 시스템이다. 회사는 다음 목표로 **2028년 3월까지 automated AI researcher**를 제시했다.

내부 사용량도 상당히 커졌다. 8월 중순 기준 연구 조직 전체에서 **사람의 1일 작업당 Agent 약 3.1 workday**가 사용됐고, Agent 사용량 중앙값에 해당하는 연구자는 API 가격 기준 하루 $600 이상, 90백분위 사용자는 하루 $7,000 이상의 추론량을 사용했다. 다만 아직 완전 자율 연구자는 아니다. 최근 6개월 동안 성공한 **4～8시간짜리 복잡한 작업의 절반 이상은 한 번 이상의 사람 개입**이 필요했다.

### 왜 중요한가

Coding Agent가 단순한 개발 보조도구를 넘어 **AI 연구 자체의 생산 수단**으로 들어갔다는 점이 핵심이다. 모델 개발 속도를 결정하는 요소가 사람 연구자의 수뿐 아니라 `동시에 돌릴 수 있는 Agent 수 × Compute × 검증 능력`으로 바뀌기 시작한다.

동시에 사람이 여전히 연구 방향을 결정하고 복잡한 작업에 개입한다는 데이터도 중요하다. 지금 단계의 현실적인 구조는 `AI 연구자 대체`보다 **사람 연구자 1명 + 여러 병렬 Agent**에 더 가깝다.

## 2. 미국 기업 AI, Closed Model 단독 사용에서 ‘Open Model Routing’으로 빠르게 이동

![AT&T open AI stack](https://tensorwave.com/api/ghost-proxy/content/images/2026/05/Blog-Telco.png)

### 핵심 요약

9월 6일 공개된 보도에 따르면 AT&T는 사내 AI 사용에서 **오픈 모델 비중을 5월 약 20%에서 현재 40%로 늘렸고, 가까운 시기에 60%까지 확대할 수 있다고 보고 있다.** AT&T는 일부 워크로드에서 올해 초 대비 AI 비용을 최대 약 80% 절감했다고 설명했다.

같은 보도에서 OpenRouter의 미국 사용 데이터를 인용해 **오픈 모델이 지난달 AI 사용의 58%를 차지했으며 1년 전 10%에서 크게 증가**했다고 전했다. Airbnb와 Deloitte 같은 기업도 오픈 모델 활용을 확대하고 있다. Deloitte는 9월 2일 아예 `Open Model Engineering` 조직을 출범시키며 기업이 오픈 모델과 독점 모델을 혼합해 Agentic AI를 구축하도록 지원한다고 발표했다.

여기서 ‘오픈 모델’에는 엄밀한 의미의 오픈소스뿐 아니라 **오픈웨이트 모델도 함께 포함**된다는 점은 구분할 필요가 있다.

### 왜 중요한가

기업의 모델 선택 기준이 `최고 Benchmark 모델 하나`에서 **업무별 Model Portfolio**로 이동하고 있다는 신호다.

`간단한 업무 → 저렴한 오픈 모델`

`고난도 추론 → Frontier closed model`

처럼 Router가 작업 난이도와 비용에 따라 모델을 선택하면, OpenAI·Anthropic 같은 Frontier 기업의 Token 가격뿐 아니라 **모델 Routing과 자체 Inference 운영 능력**이 기업 AI 비용을 좌우하게 된다.

## 3. 🔥 GitHub `diagram-design` — Agent가 Mermaid 초안을 넘어 ‘브랜드에 맞는 시각자료’를 직접 만든다

![diagram-design](https://raw.githubusercontent.com/cathrynlavery/diagram-design/main/docs/screenshots/architecture.png)

### 핵심 요약

`cathrynlavery/diagram-design`이 9월 7일 오전 GitHub Daily Trending 상위권에 올랐다. 확인 시점 GitHub API 기준 약 **32.3K Stars**이며, Daily Trending에서는 하루 **+621 Stars**가 표시됐다.

이 프로젝트는 Claude Code, Codex, Pi 등 Agent Skills 호환 환경에서 사용할 수 있는 **시각화 전용 Agent Skill**이다. 현재 README 기준 39개의 editorial diagram type을 제공하며 architecture, sequence, state machine, ER, Gantt, Sankey, Wardley map, deployment, dependency graph, UML class, database schema 등을 self-contained HTML + SVG로 생성한다.

최근 버전에서는 기존 Mermaid나 draw.io 소스를 다시 그리는 기능, 웹사이트를 읽어 브랜드 스타일을 반영하는 기능, 정적 결과를 기본으로 유지하면서 필요할 때만 motion을 추가하는 방식도 제공한다.

### 왜 중요한가

Agent Skill이 단순히 ‘좋은 Prompt 모음’에서 **전문가의 작업 방식과 디자인 규칙을 패키징한 실행 가능한 자산**으로 발전하고 있다는 좋은 사례다.

특히 문서·강의자료·기술 설계에서 AI가 만드는 시각자료의 약점은 내용보다 **일관된 디자인 품질**인 경우가 많다. 이런 Skill이 프로젝트에 남아 있으면 모델이 Claude에서 Codex로 바뀌어도 시각화 원칙과 Workflow를 계속 재사용할 수 있다.

## 4. 🔥 GitHub `AIPOCH Open Science` — 과학 Agent를 로컬 Workbench와 ‘재현 가능한 증적’에 묶는다

![AIPOCH Open Science](https://github.com/user-attachments/assets/df59db19-98d7-4071-81f2-c682fbecdf86)

### 핵심 요약

`aipoch/open-science`가 오늘 GitHub Trending에 진입했다. 확인 시점 GitHub API 기준 약 **3.8K Stars**, Daily Trending에서는 하루 **+145 Stars**가 표시됐다. Apache 2.0 오픈소스이며 macOS, Windows, Linux에서 실행되는 **local-first, model-agnostic AI research workbench**다.

핵심은 단순 연구 Chat UI가 아니다. Agent가 파일을 읽고, 웹을 검색하고, Python·R·Shell을 실행하고, PubMed·bioRxiv·유전체·화학·임상시험 등 Scientific Connector를 호출해 보고서·표·그림을 만든다. 생성된 Artifact는 immutable version으로 보관되며 **어떤 입력·코드·실행 이력·대화 branch가 결과를 만들었는지 Provenance로 추적**하도록 설계됐다.

Claude Code, OpenCode, Codex 등 Agent Runtime을 선택할 수 있고, 공식 사이트는 현재 24개의 Scientific Connector를 제공한다고 설명한다.

### 왜 중요한가

과학 분야에서 Agent의 가장 큰 문제는 ‘답을 생성할 수 있는가’보다 **그 답을 검증하고 재현할 수 있는가**다.

Open Science는 `질문 → Agent 실행 → 코드와 데이터 → 결과물 → Provenance`를 하나의 Workspace에 묶는다. 전날 OpenAI가 공개한 연구 자동화 흐름과 연결해 보면, AI Research Agent가 확산될수록 **Memory보다 한 단계 더 엄격한 Provenance와 Auditability**가 중요해질 가능성이 크다.

## 5. Thinking Machines Lab, `$5B～$6B` 신규 조달 협상 — NVIDIA가 절반 가까이 투자할 가능성

![Mira Murati](https://images.wsj.net/im-42589568/social)

### 핵심 요약

The Information의 최신 보도와 9월 6일 TNW의 후속 정리에 따르면 Mira Murati가 이끄는 Thinking Machines Lab은 **$5B～$6B 규모 신규 투자 유치**를 논의 중이며, 최소 **$40B pre-money valuation**이 거론되고 있다. Accel이 Lead 투자자로 협상 중이고 NVIDIA는 약 **$2.5B～$3B**, 즉 전체 자금의 절반가량을 투자할 수 있다고 보도됐다.

중요한 점은 아직 **확정된 Funding Round가 아니라 협상 중인 거래**라는 것이다. 초기 기사에는 $1B 수준으로 전해졌으나 The Information의 현재 보도는 $5B～$6B로 수정됐고, TNW가 9월 6일 이 차이를 명시적으로 정리했다.

### 왜 중요한가

Frontier AI Lab의 자금조달 단위가 일반 Software Startup 수준을 완전히 벗어나고 있다. Thinking Machines는 NVIDIA와 최소 1GW 규모의 Vera Rubin 인프라 배치를 추진하고 있어 모델 연구 경쟁력이 이제 **연구인력 + 알고리즘 + 수십억 달러 Compute 확보 능력**의 결합이 되고 있다.

또 NVIDIA가 GPU를 판매하는 동시에 주요 AI Lab에 대규모 Equity Capital을 공급하는 구조는 AI 산업에서 **Compute 공급자와 고객의 자본 관계가 점점 더 밀접해지고 있음**을 보여준다.

## 이번 회차 핵심

이번 다섯 소식을 연결하면 다음 흐름이 보인다.

**OpenAI Research Intern** → Agent가 연구 자체를 가속  
**Enterprise Open Models** → 업무별로 모델을 Routing  
**diagram-design** → 전문가 Workflow를 Skill로 패키징  
**Open Science** → Agent 연구 결과를 Provenance와 함께 축적  
**Thinking Machines** → 이를 확장할 Compute를 수십억 달러 단위로 조달

이번 회차에서 가장 중요한 변화는 **AI Agent가 ‘도구를 사용하는 사람의 보조자’에서 연구·개발 프로세스 안의 실제 병렬 노동력으로 들어가기 시작했다는 점**이다.

그럴수록 모델 하나의 성능보다 다음 자산의 중요성이 커진다.

> **Model Routing · Skill · Workflow · Provenance · Compute**

특히 OpenAI의 내부 데이터와 Open Science의 설계를 함께 보면, Agent가 더 오래 일할수록 단순한 Context Window 확장보다 **무엇을 했는지 남기고, 다시 검증하고, 다른 Agent가 이어받을 수 있는 구조**가 중요해지고 있다.
