# AI·LLM·AI 에이전트·테크 비즈니스 브리핑
**2026년 10월 14일 20시 KST · Asia/Seoul**

이번 회차는 공식 발표·Reuters·GitHub 원본 릴리스를 교차 확인해 **Agent 안전성 투자 1건, 피지컬 AI 장치 1건, 최근 오픈소스 릴리스 3건**을 선정했다. 직전 10월 14일 오전 브리핑의 Gemini 4 Argon, Liquid AI LFM2.5-24B-A2B, OpenIntelligentUI, OpenRig, Scaleway × AMD 등은 반복하지 않았다. 같은 날 저녁 기준 새롭게 독립 검증된 범용 프런티어 LLM 출시는 찾지 못해, 새로운 실행 기술과 오픈소스에 무게를 뒀다.

> **검증 유의:** 제조사·개발자의 성능 수치는 자체 시험 결과다. 이미 발표된 제품에 대한 당일 후속 보도와 이날 공개된 GitHub 릴리스는 구분했다. 각 이미지에는 실제 제품·프로젝트 화면인지 별도 참고 이미지인지 표시했다.

## 1. NVIDIA, 영국 Agentic AI 안전성 연구에 2억 5,000만 달러 상당 컴퓨팅 지원

![NVIDIA 로고 — 회사 식별 이미지](https://upload.wikimedia.org/wikipedia/commons/2/21/Nvidia_logo.svg)

*이미지: NVIDIA 기업 로고. 연구 현장 사진은 아니다.*

**발표·보도: 2026-10-13～14 | NVIDIA 공식 발표·Reuters**

**핵심 요약:** NVIDIA가 향후 **5년간 총 2억 5,000만 달러**, 매년 **5,000만 달러 상당의 컴퓨팅 사용권**을 영국의 자율형 AI 안전성·보안 연구에 지원한다. 이는 연구기관에 직접 지급하는 현금 2억 5,000만 달러가 아니라 **컴퓨팅 자원 가치**를 의미한다. 옥스퍼드 BOLD, UCL의 SOFAIR, 임페리얼 칼리지 런던 관련 연구가 지원 대상에 포함된다. Agent가 예상과 다른 행동을 하거나 디지털·물리적 시스템을 변경할 때 생길 위험을 평가하기 위한 연구 인프라에 해당한다.

**왜 중요한가:** Agent의 권한과 행동을 평가하려면 다양한 실패 사례를 실험·재현할 수 있는 실제 컴퓨팅 환경이 필요하다. 새로운 프런티어 모델 개발뿐 아니라 **격리 실행, 평가, 보안 연구 자체가 대규모 자원 투자를 받는 인프라 시장**으로 발전하고 있다. 다만 연구비 규모가 곧 보안 문제 해결을 의미하지는 않는다.

## 2. Hesai 'Kosmo' — LiDAR와 카메라로 로봇에 필요한 3D 공간 데이터를 수집

![Hesai Kosmo AI 공간 카메라](https://cms-image.pandaily.com/HESAI_20a63bf49c.png)

*이미지: Hesai Kosmo 장치 소개 자료. 제조사·제품 참고 이미지.*

**보도: 2026-10-14 | Reuters. 초기 공개는 9월**

**핵심 요약:** 중국 LiDAR 제조사 Hesai가 **Kosmo 공간 카메라**를 로봇 개발에 사용할 수 있는 3D 데이터 취득 도구로 강조했다. LiDAR의 깊이 정보와 카메라의 영상 정보를 결합해 현장의 입체 구조를 기록하고, 로봇 학습·시뮬레이션에 필요한 공간 데이터를 확보한다. 이 제품은 **9월에 이미 소개된 기술**이며, 10월 14일 보도는 로보틱스 사업 확대와 사용 사례를 구체화한 후속 소식이다. 관계사 Sharpa의 아이스크림 제공 로봇 사례도 제시됐지만 **99% 작업 성공률은 회사 측 주장**으로 별도 검증이 필요하다.

**왜 중요한가:** 로봇 AI에서는 LLM 텍스트 학습 데이터보다 **실제 공간·물체·행동 데이터 확보**가 큰 병목일 수 있다. 센서 → 3D 공간 모델 → 시뮬레이션·데이터셋 → 로봇 정책 학습의 흐름을 구축할 수 있어, AI 가치사슬이 클라우드 추론에서 현실 세계 데이터 수집 장치까지 넓어진다.

## 3. GitHub 'PS5LM Plus' v0.8.3 — 탈옥한 PlayStation 5 GPU에서 LLM 구동

![PS5LM Plus 실제 GPU 추론 대시보드](https://raw.githubusercontent.com/abhi245y/PS5LM/main/docs/media/app/dashboard-generating.jpg)

*이미지: 프로젝트 저장소의 실제 PS5LM Plus 화면.*

**릴리스: 2026-10-14 03:17 KST | GitHub v0.8.3**

**핵심 요약:** [abhi245y/PS5LM](https://github.com/abhi245y/PS5LM)은 Mert Cobanov가 개발한 원본 PS5LM의 **GPU 지원 포크**다. PS5에서 `llama.cpp`와 Vulkan 기반 RADV 드라이버를 사용하고 TV 대시보드, 모델 다운로드, LAN 내 채팅 웹 UI 및 OpenAI 호환 API를 제공한다. 개발자 측 측정에 따르면 **2비트 양자화 Qwen3.8 27B**가 약 **20토큰/초**, Gemma 4 E4B가 약 **61토큰/초**에 도달한다. PS5의 약 11.44GiB 단일 GPU 메모리 힙을 활용한다. **탈옥·홈브루 환경이 필요하고 Sony 공식 지원 기능이 아니다.** 다른 콘솔·펌웨어에서도 재현된 범용 성능을 뜻하지 않는다.

**왜 중요한가:** 저비용 로컬 LLM의 실용성은 모델 크기뿐 아니라 **하드웨어 접근 방법, 양자화, 추론 엔진, 메모리 설계**에 좌우된다. 범용 게이밍 GPU의 활용 가능성을 보여주는 실험이며, 원본의 CPU 전용 구동과 비교해 GPU 백엔드가 갖는 차이를 직관적으로 보여준다. 일반 사용자의 즉시 설치용 제품이라기보다 연구·개발자 프로젝트다.

출처: [PS5LM Plus GitHub](https://github.com/abhi245y/PS5LM), [v0.8.3 릴리스](https://github.com/abhi245y/PS5LM/releases/tag/v0.8.3), [원 개발자 PS5LM](https://github.com/cobanov/PS5LM)

## 4. GitHub 'SolidCraft' v0.9.0 — 순수 Rust CAD, AI Agent가 MCP로 직접 3D 모델 편집

![SolidCraft 실제 매개변수 CAD 모델링 시연](https://raw.githubusercontent.com/bherbruck/solidcraft/main/docs/screenshots/demo-0.8.gif)

*이미지: 공식 저장소의 실제 매개변수 기반 모델링 데모. GIF는 이전 버전 0.8 시연 자료.*

**릴리스: 2026-10-14 05:31 KST | GitHub v0.9.0**

**핵심 요약:** [bherbruck/solidcraft](https://github.com/bherbruck/solidcraft)는 **Rust로 만든 오픈소스 매개변수 기반 3D CAD 애플리케이션**이다. 스케치, 치수와 제약 조건, 돌출, 필렛, 파라미터 변경 시 재계산되는 피처 타임라인을 제공한다. 데스크톱과 브라우저에서 사용할 수 있으며 내장 **MCP 서버**를 통해 AI Agent가 CAD 객체를 생성·수정할 수 있다. 프로젝트는 공개 참조 부품 **76개 중 75개**가 분석 결과 또는 FreeCAD 기준 계산값과 부합하며 **1개는 알려진 오류**라고 명시한다. 아직 초기 제품으로 파일 호환성과 기하학적 정확성을 실제 사용 조건에서 검증해야 한다.

**왜 중요한가:** 이전 회차에 다룬 `text-to-cad`가 **Agent를 위한 CAD 활용 Skills** 중심이었다면 SolidCraft는 **편집 가능한 모델의 실제 CAD 엔진과 UI·MCP 인터페이스를 통합**한다. 사람이 도면을 손으로 수정하는 방식과 Agent가 파라미터를 변경하는 방식을 같은 데이터 모델로 연결할 수 있다.

출처: [SolidCraft GitHub와 실제 데모](https://github.com/bherbruck/solidcraft), [v0.9.0 릴리스](https://github.com/bherbruck/solidcraft/releases/tag/v0.9.0)

## 5. GitHub 'AIPOCH Open-Science' v0.37.2 — 연구 결과의 출처·실행 기록까지 보존하는 AI 연구 워크벤치

![AIPOCH Open-Science 공식 프로젝트 화면 배너](https://raw.githubusercontent.com/aipoch/open-science/main/docs/images/readme/open-science-banner.png)

*이미지: 프로젝트 저장소의 공식 제품 소개 배너.*

**릴리스: 2026-10-13 14:10 KST | GitHub v0.37.2**

**핵심 요약:** [aipoch/open-science](https://github.com/aipoch/open-science)는 **Apache 2.0 오픈소스, 로컬 우선, 모델 비종속** 과학 연구용 Agent 작업환경이다. 자료 조사, 문헌 분석, 연구용 데이터 연결, Python/R Notebook 실행, 보고서·표·시각화 생성 기능을 하나의 공간에 제공한다. 중요한 기능은 생성된 자료의 코드·입력 파일·실행 환경·대화 분기를 추적하고, 최종 기록을 **`.science` 패키지**로 내보내 연구자가 나중에 검토·이관할 수 있다는 점이다. 실제 공개된 최신 설치 릴리스는 **v0.37.2**이며, GitHub의 미래 계획·문서에 적힌 버전과 구분했다.

**왜 중요한가:** AI가 연구 결과를 잘 생성하는 것과 **그 결과를 재현·감사할 수 있는 것**은 다르다. 모델이 임의로 생성한 보고서가 아니라 실행 코드, 파일 버전, 검증 근거까지 연결해야 과학 연구와 전문 분석에 유용하다. 단, '로컬 우선'이 모든 자료의 외부 전송 차단을 뜻하지는 않는다. 사용자가 선택한 외부 LLM과 데이터 커넥터에는 자료가 전달될 수 있다.

출처: [AIPOCH GitHub](https://github.com/aipoch/open-science), [v0.37.2 릴리스](https://github.com/aipoch/open-science/releases/tag/v0.37.2)
