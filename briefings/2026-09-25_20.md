## 1. Gemini 3.8 Live with Live Avatar
**핵심 요약:** Google이 Gemini Enterprise에 Live Avatar를 정식 출시했다. 실시간 음성에 저지연 비디오, 립싱크, 표정 생성을 결합하고 97개 언어와 비동기 Tool Call을 지원한다.
**왜 중요한가:** Voice Agent가 화면 없는 음성비서에서 시각적 존재감을 가진 실시간 멀티모달 Agent로 확장되고 있다.
- https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/

## 2. Meta Muse의 디바이스 확장
**핵심 요약:** Meta는 Muse를 AI Glasses로 확대하고 전용 이메일과 Mac 앱 제어 기능을 공개했다. 사용자가 자리를 비운 뒤에도 Queue 작업을 계속 수행할 수 있다.
**왜 중요한가:** Personal Agent 경쟁이 단일 앱에서 PC·이메일·웨어러블을 잇는 상시 실행 Agent 경쟁으로 이동하고 있다.
- https://about.fb.com/news/2026/09/the-biggest-news-from-connect-2026/

## 3. Linux Kernel도 AGENTS.md 검토
**핵심 요약:** Linux Kernel 개발자들이 Coding Agent가 따라야 할 Repository 작업 규칙을 담는 AGENTS.md 추가를 검토하고 있다.
**왜 중요한가:** README가 사람을 위한 안내라면 AGENTS.md는 Agent가 코드베이스에서 일하는 방법을 설명하는 표준 인터페이스로 자리 잡고 있다.
- https://www.phoronix.com/news/Linux-Considers-AGENTS-MD

## 4. 🔥 vectorize-io/hindsight
**핵심 요약:** GitHub에서 급상승 중인 Hindsight는 Facts·Experiences·Observations·Mental Models를 분리하고 retain·recall·reflect로 장기 기억을 관리한다. 주요 Coding Agent와 Framework, MCP를 폭넓게 지원한다.
**왜 중요한가:** 장기 Agent의 경쟁력이 Context Window 크기뿐 아니라 경험을 축적하고 재사용하는 지속형 Memory 계층으로 이동하고 있다.
- https://github.com/vectorize-io/hindsight

## 5. OpenClaw 2026.9.6
