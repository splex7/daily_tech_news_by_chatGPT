# AI·LLM·에이전트 최신 브리핑

**2026년 9월 27일 20시 KST**

직전 9월 27일 08시 브리핑의 OpenAI Agent Sandbox 사고, Julia 1, Exa Agent Ultra, Google Antigravity Local Model, Xing4.0-29B-A4B는 중대한 후속이 없어 제외했다. 이번 회차는 **Long-horizon Agent Model, Multimodal Decision Model, Agent Memory, Visual Agent Interface, Vertical Enterprise Agent**를 중심으로 선정했다.

## 1. Meituan `LongCat-2.5-Preview` — 1M Context·Native Multimodal을 장착한 장기 실행 Agent 모델

**핵심 요약:** Meituan이 9월 25일 `LongCat-2.5-Preview`를 공개했다. 공식 페이지는 1M Context, Native Tool Calling, Multi-step Reasoning, 강화된 Coding과 Multimodal 능력을 핵심으로 내세우며 Claude Code, Hermes, OpenClaw, OpenCode, Kilo Code와의 호환을 지원한다. 공개된 모델 라우팅 정보 기준으로는 약 1.6T MoE 중 약 48B가 활성화되며 최대 출력은 약 128K다. 아직 공식 Benchmark는 공개되지 않았기 때문에 성능 우위는 검증이 필요하다.

**왜 중요한지:** Frontier Model 경쟁이 단순 Chat Benchmark에서 **긴 Context를 유지하며 여러 Tool을 오랫동안 호출하는 Agent 작업**으로 이동하고 있다. 1M Context와 Native Multimodal을 동시에 Agent 개발환경에 붙인다는 점에서 LongCat은 중국 모델 진영의 Long-horizon Agent 경쟁이 빠르게 심화되고 있음을 보여준다.

- 공식: https://longcat.ai/
- API 문서: https://longcat.ai/platform/docs/catpaw
- 모델 정보: https://vercel.com/ai-gateway/models/longcat-2.5-preview

## 2. 🔥 InternLM `Intern-Decision-4B` — 이미지까지 보고 여러 결정을 한 번에 내리는 Decision Model

**핵심 요약:** InternLM이 Apache 2.0 기반 `Intern-Decision` 계열을 공개했다. 4B 모델은 Qwen3.5-4B에서 Fine-tuning한 Multimodal Structured Decision Model로, State와 Question Schema, 선택적 이미지를 입력받아 자유문장을 생성하지 않고 각 선택지의 확률 분포를 한 번의 Forward Pass에서 반환한다. 하나의 요청에서 1～16개 질문과 질문당 최대 62개 후보, 최대 8개 이미지를 처리할 수 있다.

연구팀 자체 평가에서는 4B 모델이 7개 평가 평균 90.02로 Jev의 88.74를 앞섰고, RTX 4090에서 평균 44.16ms의 End-to-end Latency를 기록했다. 이는 공개 Model Card에 기재된 자체 평가이므로 독립 검증과 구분해서 볼 필요가 있다.

**왜 중요한지:** 최근 Jev, CLM, Julia로 이어진 `System One` 계층이 **Multimodal + Multi-decision**으로 확장되고 있다. Agent가 매번 Frontier LLM으로 문장을 생성하지 않고 Tool Routing, 승인, 위험판정, UI 상태판단 같은 반복 의사결정을 작은 모델에 넘기면 비용과 Latency를 크게 줄일 수 있다.

- Model Card: https://huggingface.co/internlm/Intern-Decision-4B
- GitHub: https://github.com/InternLM/Intern-Decision

## 3. GitHub `Agentic Autofix + Copilot Memory` — 보안 Agent가 수정 패턴을 기억한다

**핵심 요약:** GitHub가 Agentic Autofix에 Copilot Memory를 연결했다. Memory가 활성화된 Repository에서는 Autofix가 기존 Memory를 참고해 Security Alert를 해결하고, 수정이 성공하면 그 Fix Pattern을 다시 Memory로 저장한다. 이렇게 축적된 Repository별 보안 패턴은 이후 다른 Alert뿐 아니라 Copilot Code Review와 Copilot Cloud Agent에서도 재사용될 수 있다. 두 기능은 현재 Public Preview다.

**왜 중요한지:** Coding Agent가 **Stateless Patch Generator**에서 Repository 고유의 보안 지식을 누적하는 학습형 작업자로 바뀌기 시작했다. 한 Agent가 발견한 Secure Coding Pattern을 다른 Agent가 공유한다면 조직의 Agent들이 작업할수록 Repository-specific Knowledge가 축적되는 구조가 만들어진다.

- GitHub Changelog: https://github.blog/changelog/2026-09-25-agentic-autofix-now-uses-copilot-memory/

## 4. 🔥 `drawgent` — Claude Code·Codex가 Excalidraw 캔버스 안에서 직접 그림을 고친다

**핵심 요약:** 오픈소스 프로젝트 `drawgent`가 Claude Code, Codex, opencode를 Live Excalidraw Whiteboard에 연결했다. 사용자는 Chat Panel에서 Diagram을 요청하거나 캔버스 특정 위치에 `AGENT:` 지시를 적을 수 있다. Agent는 Screenshot과 Scene 정보를 읽고 캔버스를 직접 편집한 뒤 결과를 확인하고 작업 표시를 `DONE`으로 바꾼다. ACP로 Agent Session을 연결하고 MCP Tool로 Canvas를 조작하는 구조다.

**왜 중요한지:** Coding Agent의 작업면이 **File + Terminal + Browser**에서 **Spatial Canvas**까지 확장되고 있다. 특히 사람이 Agent가 수정하는 Diagram을 실시간으로 보면서 같은 공간에서 개입할 수 있다는 점은 Architecture Design, UML, 시스템 설계처럼 시각적 결과물이 중요한 업무에서 새로운 Human-Agent 협업 패턴을 제시한다.

- Source: https://tangled.org/primogen.tngl.sh/drawgent/blob/main/README.md

## 5. Warp 2.0 `Warp Agent` — HR SaaS가 항상 켜져 있는 업무 담당자로 변한다

**핵심 요약:** HR·Payroll 스타트업 Warp가 Warp 2.0과 함께 `Warp Agent`를 출시했다. Agent는 신입사원 Onboarding, 주별 Tax Registration, Payroll 설정, Benefits·401k 등록, Laptop 주문, Google·Slack 계정 생성, Tax Notice 처리 등을 Event 또는 Schedule 기반 `Routines`로 실행한다. 사용자는 자연어로 Routine을 만들 수 있고, 각 Routine에는 Autonomy Level과 실행 Log가 있다. Agent는 자신이 대신 행동하는 사람보다 더 넓은 권한을 가질 수 없도록 설계됐다.

**왜 중요한지:** Enterprise Agent가 Dashboard 옆의 Chatbot에서 **업무를 스스로 소유하는 Always-on Operator**로 이동하는 사례다. 실제 기업 Agent 제품의 핵심 경쟁력이 LLM 자체보다 Context, Identity, Permission, Approval, Audit, Rollback을 얼마나 잘 묶느냐에 있다는 점을 보여준다.

- 공식 발표: https://www.warp.co/blog/warp-agent
