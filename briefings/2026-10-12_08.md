## 1. Amazon, 실시간 영상 AI 스타트업 Decart 약 70억 달러 인수 협상

![Decart Lucy 2.0 실시간 영상 변환 시연](https://the-decoder.com/wp-content/uploads/2026/01/Decart-Lucy2-1200x692.png)

*이미지: Decart의 기존 Lucy 2.0 실시간 영상 변환 시연. 인수 협상 장면은 아닙니다.*

**보도: 10월 11일 · Reuters가 WSJ 인용**

**핵심 요약:** Amazon이 AI 스타트업 **Decart를 약 70억 달러에 인수**하는 방안을 논의 중이라는 보도가 나왔습니다. Decart의 **Lucy**는 실시간 영상 변형, **Oasis**는 상호작용 가능한 시뮬레이션 환경 생성에 초점을 둡니다. Decart는 지난 5월 약 40억 달러 가치평가를 받은 것으로 전해졌습니다. **계약은 체결되지 않았으며 Reuters는 WSJ 보도를 독립적으로 확인하지 못했습니다.**

**왜 중요한가:** 거래가 성사된다면 Amazon은 AWS의 GPU·Trainium 컴퓨팅 사업에 영상·월드모델 기술을 결합할 수 있습니다. AI의 경쟁이 대화 모델에서 **실시간 생성·시뮬레이션·클라우드 플랫폼**으로 넓어지는 흐름입니다. 다만 인수 효과와 계약 성사는 불확실합니다.

출처: [Reuters, 2026-10-11](https://www.reuters.com/business/retail-consumer/amazon-talks-buy-ai-startup-decart-around-7-billion-wsj-reports-2026-10-11/), [Decart](https://decart.ai/)

## 2. Google, 자연어만으로 게임 만드는 Playground 출시…Unity Spark 예고

![Google AI 기반 인터랙티브 게임 제작 참고 화면](https://storage.googleapis.com/gweb-developer-goog-blog-assets/images/5Gxf4n89p76XWyJ.original.png)

*이미지: Google AI Studio로 만든 I/O 인터랙티브 게임의 참고 화면. 이번 Playground의 실제 UI는 아닙니다.*

**출시: 10월 7일 · Google 공식 발표**

**핵심 요약:** Google Labs가 게임 아이디어를 텍스트로 설명해 **브라우저 게임을 만들고 즉시 플레이·수정·공유**하는 Playground를 출시했습니다. 규칙·물리 동작·캐릭터도 대화로 수정합니다. **미국 18세 이상** 대상 초기 서비스로, 제작 기능 접근은 Google AI 요금제에 따라 차이가 있습니다. Unity와의 협업 제품 **Unity Spark는 아직 개발·테스트 중이며**, 고급 3D 게임 제작 기능을 향후 제공할 예정입니다.

**왜 중요한가:** Vibe Coding이 단순한 웹페이지를 넘어 **실행 가능한 인터랙티브 콘텐츠의 즉석 제작**으로 이동합니다. 게임 프로토타입, 교육용 시뮬레이션, 간단한 체험형 서비스의 제작 비용을 낮출 수 있지만 완성도·저작권·검증 문제는 남습니다.

출처: [Google 공식 블로그, 2026-10-07](https://blog.google/innovation-and-ai/technology/ai/playground-experimental-gaming-platform/), [Unity 공식 발표](https://unity.com/news/google-and-unity-partner-on-new-ai-gaming-platform-for-the-next-era-of-interactive-entertainment)

## 3. GitHub Trending: AirLLM, VRAM 4GB로 70B LLM 실행…스트리밍 학습까지

![AirLLM 프로젝트 로고](https://raw.githubusercontent.com/lyogavin/airllm/main/assets/airllm_logo_sm.png)

**GitHub Trending: 10월 12일 확인 · 기존 프로젝트의 2026년 9월 기능 업데이트**

**핵심 요약:** 오픈소스 [lyogavin/airllm](https://github.com/lyogavin/airllm)이 GitHub Trending에서 **약 3.64만 Stars, 최근 하루 +541 Stars**로 다시 주목받았습니다. 모델을 레이어 단위로 저장장치에서 읽어 GPU로 순차 전송해, **70B 모델을 VRAM 4GB 장치에서도 실행**하도록 설계했습니다. 개발자는 9월 업데이트에서 Qwen3.8-Flash-Next 125B의 어댑터 학습을 **VRAM 6GB 미만**으로 수행했다고 설명합니다. 이는 개발자 자체 결과입니다.

**왜 중요한가:** 필요한 **GPU 메모리를 줄이는 것**과 **추론 속도를 높이는 것**은 다릅니다. 모델 가중치는 여전히 저장장치·시스템 메모리에 필요하고 로딩 지연이 커질 수 있습니다. 그럼에도 소형 GPU로 큰 모델을 실험하거나 파인튜닝하는 접근성을 넓혀 줍니다.

## 5. Rubrik, Claude Mythos 5 기반 Code Guardian 공개…격리된 복제 저장소에서 공격 경로 분석

![Rubrik Agent Cloud 관련 화면](https://www.rubrik.com/content/dam/rubrik/blog/image/img-blog-agent-claude-actions.webp)

*이미지: Rubrik의 Agent 보안 관련 참고 이미지. Code Guardian의 확정된 제품 UI는 아닙니다.*

**발표: 10월 8～9일 · Rubrik 공식 발표**

**핵심 요약:** Rubrik이 Anthropic의 **Claude Mythos 5**와 보안용 Harness를 결합한 **Code Guardian**을 Project Hourglass 파트너 프로그램에 추가했습니다. 실제 운영 저장소를 직접 공격하는 대신 **복제된 격리 환경**에서 다단계 공격 경로를 분석하고, 취약점의 사업상 우선순위를 판단하며, 코드 복구 체계를 연계하는 방식입니다. 발표 시점에 일반 사용자에게 무제한 제공되는 제품으로 확인된 것은 아닙니다.

**왜 중요한가:** 개발 Agent의 코드 생산성이 높아질수록 보안검사도 단순 패턴 매칭을 넘어 **공격 시나리오 기반 검증**으로 이동합니다. 다만 AI가 찾아낸 취약점은 오탐 가능성이 있으므로 사람의 재현 검증, 접근 통제, 수정 승인 절차가 필요합니다.

출처: [Rubrik 공식 발표, 2026-10-08](https://ir.rubrik.com/news-events/press-releases/news-details/2026/Rubrik-Expands-Project-Hourglass-with-Rubrik-Code-Guardian-Powered-by-Claude/default.aspx)
