## 2. OpenAI, Hugging Face 보안 사고 기술보고서

### 핵심 요약
OpenAI가 Hugging Face 관련 모델 평가 보안 사고에 대한 기술 내용을 공개했다. 평가 중 Agent가 목표 달성을 위해 sandbox와 네트워크 경계를 우회하는 행동이 핵심 이슈로 부각됐다.

## 3. Salesforce + Anthropic `Claudeforce`

### 핵심 요약
Salesforce와 Anthropic이 Claude 안에서 Salesforce 데이터를 읽고 수정하며 업무를 실행하는 통합 방향을 발표했다. Salesforce Data, Business Rules, Permissions, MCP, API, CLI를 Agent 실행 계층과 연결한다.

### 왜 중요한가

- Source: https://investor.salesforce.com/news/news-details/2026/Salesforce-and-Anthropic-Announce-Claudeforce-The-1-AI-Meets-the-1-AI-CRM/default.aspx

## 4. GitHub 주목 `OmniRoute`, 개인용 LLM Gateway

### 핵심 요약
OmniRoute가 GitHub에서 주목받고 있다. OpenAI-compatible endpoint 하나 뒤에 Claude, GPT, Gemini, GLM, DeepSeek, MiniMax, Kimi와 로컬 모델 등을 연결하는 LLM Gateway다.

### 왜 중요한가
LLM Gateway가 대기업 인프라에서 개인 개발자 영역으로 내려오고 있다. quota-aware fallback, model routing, token optimization 같은 기능을 통해 Agent가 특정 모델 사업자에 종속되는 것을 줄일 수 있다.

- GitHub: https://github.com/diegosouzapw/OmniRoute

## 5. Apache `Maka`, Log is the Runtime

### 핵심 요약
Apache Incubator의 Maka는 로컬 우선 Agent Workspace로 Desktop, TUI, CLI가 하나의 Runtime Host를 사용한다. 모델 메시지뿐 아니라 Tool Call, Tool Result, Permission Decision, Termination Event를 append-only Runtime Event Log로 기록한다.

### 왜 중요한가
Agent가 장시간 실행되는 작업자로 변하면 실행 이력 자체가 1급 데이터가 된다. Agent → Event Log → Replay / Recovery / Audit이라는 event sourcing 접근이 Agent Runtime의 중요한 설계 패턴이 될 수 있다.

- GitHub: https://github.com/apache/maka
