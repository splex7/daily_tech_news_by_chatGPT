## 1. OpenAI, Codex에 장시간 실행되는 `Persistent mode` 개발 중

### 핵심 요약
WIRED가 OpenAI의 공개 Codex CLI 코드 변경을 검토해, Codex가 사용자가 중단할 때까지 계속 작업하고 스스로 후속 작업을 생성하는 `Persistent mode`와 `proactivity` 기능을 개발 중이라고 보도했습니다. 아직 정식 출시된 기능은 아닙니다. OpenAI의 현재 Codex 제품도 이미 일정 예약과 백그라운드 작업을 강조하고 있어, 장기 실행형 Agent로 가는 방향과 일치합니다.

### 왜 중요한지
Agent의 경쟁 포인트가 `한 번의 요청을 얼마나 잘 처리하나`에서 `며칠간 지속적으로 목표를 추적하고 후속 작업을 스스로 만들어내나`로 이동하고 있습니다. 이는 Agent Runtime에서 권한, 중단 제어, 장기 메모리, 비용 제한, 감사 로그가 더 중요해진다는 의미입니다.

Sources:

## 2. Google, `Gemini 3.8 Flash` 내부 테스트 시작 보도

### 핵심 요약
Business Insider에 따르면 Google 직원들이 내부 코딩 플랫폼 Jetski에서 차세대 `Gemini 3.8 Flash`를 테스트하고 있습니다. 공개 출시는 아직 확인되지 않았으며, 최근 3.6과 3.7 Flash 이후 빠르게 이어지는 후속 버전입니다.

### 왜 중요한지
Agent와 코딩 워크로드는 토큰 소비량이 매우 크기 때문에 최고 성능 모델보다 `충분히 강하면서 빠르고 싼 모델`의 가치가 커지고 있습니다. Google이 Flash 계열을 월 단위에 가까운 속도로 갱신한다면, 향후 Agent 경쟁은 flagship 성능뿐 아니라 추론비용과 지속 실행 효율에서 갈릴 가능성이 큽니다.

Source:
- https://www.businessinsider.com/google-employees-testing-next-gemini-flash-3-8-model-2026-8

## 3. DeepSeek, 약 `$7.4B` 조달하며 `$74B` 가치평가 추진 보도

### 핵심 요약
Wall Street Journal에 따르면 DeepSeek은 약 74억 달러 규모의 신규 자금조달을 추진하며 기업가치 약 740억 달러를 목표로 하고 있습니다. 보도 기준 연환산 매출은 약 5억 달러이며, 내년 상하이 IPO도 계획 중입니다.

## 4. OpenAI·Anthropic·Google·Microsoft 등 100개 이상 조직, AI 사이버 방어 공동행동 촉구

### 핵심 요약

## 5. GitHub 급상승 `freestylefly/awesome-gpt-image-2` — Prompt를 Agent Skill로 패키징

### 핵심 요약
GitHub Trending 집계에서 `freestylefly/awesome-gpt-image-2`가 하루 약 2천 개 수준의 Star를 추가하며 상위권에 올랐습니다. 이 저장소는 500개가 넘는 GPT-Image2 사례와 20개 이상의 산업용 템플릿을 `Prompt as Code` 방식으로 구조화하고, 동일한 자료를 Claude Code와 Codex에서 설치 가능한 Agent Skill로 제공합니다.

### 왜 중요한지
Prompt가 단순 텍스트 자산에서 `버전 관리 가능하고 설치 가능한 실행 자산`으로 변하고 있습니다. 특히 동일 Skill을 Claude Code, Codex, Cursor 등 여러 Agent가 재사용하도록 만드는 패턴은 MCP 이후 Agent 생태계의 다음 패키지 계층이 될 가능성이 있습니다.

Sources:
- https://github.com/freestylefly/awesome-gpt-image-2
- https://reporadar.spreix.com/reports/daily/2026-08-27

## 이번 회차의 핵심

가장 큰 흐름은 `Agent의 지속성`입니다. OpenAI의 Persistent mode, 사이버 방어 공동서한, Prompt를 설치 가능한 Skill로 만드는 GitHub 프로젝트가 모두 같은 방향을 가리킵니다. Agent가 오래 실행되고 더 많은 시스템에 접근할수록 모델 자체보다 Runtime, Permission, Skill, Audit 계층의 중요성이 빠르게 커지고 있습니다.
