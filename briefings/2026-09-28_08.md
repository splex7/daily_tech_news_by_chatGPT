# AI·LLM·에이전트 최신 브리핑

**2026년 9월 28일 08시 KST**

직전 브리핑의 LongCat-2.5, Intern-Decision-4B, GitHub Agentic Autofix + Copilot Memory, drawgent, Warp Agent는 중대한 후속이 없어 제외했다. 이번 회차는 **새 코딩 모델, Agent Web 경제, Agent-native 협업, Agent 보안 경계, 재사용 가능한 멀티모달 Skill** 흐름을 중심으로 선정했다.

## 1. MiniMax `M3.1-Flash-Preview` — 새 코딩 모델을 MiniMax Code에 먼저 투입

**핵심 요약:** MiniMax가 9월 27일 `M3.1-Flash-Preview`를 MiniMax Code에 넣었고, 현재 MiniMax 공식 Agent 페이지에서도 기본 모델로 표시된다. 공개된 설명은 일상 개발, Bug 수정, 기능 구현 같은 Coding Workflow를 겨냥한다. 다만 현재 공개 Model Card, 공식 Benchmark, 독립 API 가격과 상세 사양은 아직 충분히 공개되지 않았다. 일부 보도에서는 MiniMax Code가 low, medium, high, xhigh, max의 다섯 단계 reasoning effort를 노출한다고 전한다.

**왜 중요한가:** 모델을 먼저 API나 Model Card로 공개한 뒤 제품에 넣는 순서가 아니라, **Agent 제품 안에서 먼저 배포하고 실제 Workflow로 검증하는 방식**이 뚜렷해지고 있다. Coding Model 경쟁도 단순 Benchmark 점수보다 Harness 통합, Latency, Reasoning Budget 조절, End-to-end 작업 완성도로 이동하고 있다.

- MiniMax Code: https://agent.minimax.io/code/desktop/goal
- 보도: https://alphasignal.ai/news/minimax-quietly-slips-m3-1-flash-preview-into-its-coding-tool

## 2. Cloudflare: 자동화 트래픽이 이미 인간 트래픽 추월 — Agent Web 경제가 시작됐다

**핵심 요약:** Cloudflare는 9월 27일 창립자 서한에서 자사 네트워크 기준 자동화 트래픽이 인간 트래픽을 추월한 시점이 당초 예상한 2027년 하반기보다 훨씬 빠른 **2026년 5월**이었다고 밝혔다. 현재 추세가 이어지면 5년 뒤 자동화 트래픽이 인간 트래픽의 1,000배가 될 수 있다고 전망했다. Agent가 한 번의 추천을 위해 수백～수천 개 페이지를 읽으면서 사이트 운영자는 트래픽 비용을 부담하지만 실제 거래나 방문은 한 곳에만 돌아가는 문제도 지적했다.

**왜 중요한가:** Agent가 웹의 주요 소비자가 되면 기존의 SEO, 광고, Crawling, Rate Limit, 콘텐츠 보상 모델이 전부 바뀐다. 앞으로 웹사이트는 사람에게 페이지를 보여주는 것뿐 아니라 **Agent에게 데이터를 효율적으로 제공하고, 접근을 통제하고, 사용 대가를 받는 인터페이스**까지 설계해야 할 가능성이 크다.

- Cloudflare 공식 발표: https://blog.cloudflare.com/cloudflares-2026-annual-founders-letter/

## 3. Ando — AI Agent를 봇이 아니라 ‘팀원’으로 넣는 메신저에 $20M 투자

**핵심 요약:** Ando가 9월 24일 Stealth에서 나오며 Accel, Index Ventures, Emergence Capital 등으로부터 **$20M** 투자를 발표했다. Ando는 Slack에 Agent Bot을 붙이는 방식이 아니라 처음부터 사람과 Agent가 함께 일하도록 만든 Messaging Platform이다. Agent는 Channel, Thread, Live Conversation에 참여하며 Persistent Identity, Permission, Shared Context와 Memory를 가진다. Codex, Claude, Grokbot 등 외부 Agent도 연결할 수 있다.

**왜 중요한가:** 여러 Agent가 실제 동료처럼 일하기 시작하면 기존 Collaboration Software의 기본 단위도 바뀐다. 메시징이 단순 대화 기록이 아니라 **사람과 Agent가 Context를 축적하고 업무를 인계하며 서로의 작업을 검토하는 Control Surface**가 될 수 있다. Agent 시대에 Slack이나 Teams의 다음 형태를 보여주는 초기 사례다.

- Ando 공식 소개: https://www.ando.so/blog/introducing-ando
- 투자 발표: https://www.globenewswire.com/news-release/2026/9/24/3368344/0/en/ando-launches-agent-native-messaging-platform-announces-20-million-seed.html

## 4. 🔥 `Pipelock v3.5.0` — MCP·A2A까지 검사하는 오픈소스 Agent 방화벽

**핵심 요약:** Apache 2.0 오픈소스 `Pipelock`의 현재 릴리스는 v3.5.0이다. Agent와 Network 사이에 독립적인 Egress Proxy를 두고 HTTP, WebSocket, MCP, A2A 트래픽과 TLS Interception이 활성화된 CONNECT 내용을 검사한다. Secret Exfiltration, Prompt Injection, SSRF, Tool Poisoning, 위험한 Tool-call Chain 등을 탐지하며 65개의 내장 DLP Pattern을 제공한다. 특히 허용·차단 결정에 대해 Agent Runtime 밖에서 검증할 수 있는 **Mediator-signed Action Receipt**를 만든다. 배포 Artifact에는 SLSA Provenance, CycloneDX SBOM, Signed Container Image도 제공한다.

**왜 중요한가:** 최근 Agent 사고들이 보여준 핵심은 모델이 스스로 안전 규칙을 지키기를 기대하는 것만으로는 부족하다는 점이다. Pipelock은 보안 경계를 모델 밖의 Network Mediation Layer로 옮긴다. 즉 Agent Security가 **Prompt Filter → Egress Control + Signed Evidence + Runtime Policy**로 이동하는 흐름을 잘 보여준다.

- GitHub: https://github.com/luckyPipewrench/pipelock

## 5. 🔥 Qwen `Qwen-MM-Plugins` — 어떤 Agent Harness든 멀티모달로 만드는 Skill + MCP 계층

**핵심 요약:** Alibaba Qwen의 Apache 2.0 프로젝트 `Qwen-MM-Plugins`는 현재 약 3K GitHub Stars를 기록하며 기능 범위를 빠르게 넓히고 있다. Core는 이미지·비디오·문서·3D 파일을 읽고 OCR, Grounding, Segmentation, ASR 등을 제공한다. 9월 16일에는 시연 영상을 재사용 가능한 Agent Skill로 변환하는 `omni-skill-creator`가 추가됐고, 9월 20일에는 실제 Hardware를 조작하는 MHS와 이미지·영상의 3D Spatial Reasoning을 위한 `video-spatio`가 추가됐다. Claude Code, Codex, OpenClaw, Qwen Code 등 여러 Harness에서 Skill + MCP 방식으로 설치할 수 있다.

**왜 중요한가:** 멀티모달 능력이 특정 모델의 API 기능으로만 존재하는 대신 **재사용 가능한 Agent Capability Package**로 분리되기 시작했다. 모델이나 Harness를 바꿔도 Vision, Video Memory, Editing, 3D, Hardware Control 같은 능력을 Skill + MCP 형태로 계속 가져갈 수 있다면 Agent 생태계에서 중요한 자산은 모델 자체뿐 아니라 이러한 Capability Layer가 된다.

- GitHub: https://github.com/QwenLM/Qwen-MM-Plugins
