**2026년 9월 12일 08시 KST 기준**

직전 9월 11일 20시 브리핑의 OpenAI Agents API, GPT-Live-1, Anthropic Threat Intelligence Report, OpenMAIC, Positron AI는 중대한 새 업데이트가 없어 제외했다. 이번 회차는 9월 11일 새로 공개된 멀티모델 오케스트레이션, 오픈소스 Agent Harness, 로컬 Agent 추론 인프라, 기업용 Sovereign AI, 중국 AI 반도체 자본시장에 비중을 뒀다.

## 1. Sakana AI `Fugu Max`·`Fugu Ultra v2` — 하나의 더 큰 모델보다 여러 모델을 학습해서 지휘한다

![Sakana Fugu](https://sakana.ai/assets/fugu-release/benchmark-fugu-grid.png)

**핵심 요약:** Sakana AI가 9월 11일 `Fugu Max`와 `Fugu Ultra v2`를 공개했다. Fugu는 단일 Foundation Model이 아니라 여러 Open-weight·Specialized Model을 작업별로 선택하고 조합하는 학습된 Multi-Agent Orchestration System이다. Fugu Max는 비용 대비 성능을, Ultra v2는 복잡한 다단계 문제에서 최대 성능을 목표로 한다.

Sakana 자체 평가에서 Fugu Max는 Terminal Bench 2.1, GPQA-D, AutomationBench 등 10개 평가 중 7개에서 기존 단일 모델의 비용·성능 경계를 확장했다고 주장한다. 가격은 100만 Token당 입력 $2, 출력 $6다. Fugu Ultra v2는 Chartography 48.3, DeepSWE 74.3을 보고했으며 Fable 5, Fable 5.1, GPT-6 Astra는 Orchestration Pool에 포함하지 않았다고 밝혔다. 두 제품 모두 OpenAI-compatible API로 즉시 제공된다. 수치는 출시사 자체 평가이므로 독립 재현 결과와는 구분해서 볼 필요가 있다.

**왜 중요한지:** 최근까지 Model Routing은 주로 사람이 만든 규칙이나 비용표에 따라 `쉬운 요청은 작은 모델, 어려운 요청은 큰 모델`로 보내는 방식이었다. Fugu는 그 선택과 분해·검증·합성을 학습된 시스템 자체에 맡긴다. Frontier Intelligence의 경쟁 단위가 `가장 큰 단일 모델`에서 `어떤 모델들을 어떤 순서와 역할로 조직하느냐`로 이동할 수 있다는 강한 신호다.

- Sakana AI 공식 발표: https://sakana.ai/fugu-max-release/

## 2. 🔥 GitHub `TrueForge` — Agent Harness를 모델 공급자와 분리한 MIT 오픈소스 Runtime

![TrueForge Agent Harness](https://cdn.prod.website-files.com/6295808d44499cde2ba36c71/6a153efdaefa2e54437c3fe8_WhatsApp%20Image%202026-05-26%20at%2011.51.01-p-1080.jpeg)

**핵심 요약:** TrueFoundry가 9월 11일 `TrueForge`를 공식 출시했다. 현재 GitHub 약 5.4K Stars의 MIT 오픈소스 Agent Harness로, OpenAI·Anthropic·Gemini뿐 아니라 OpenAI-compatible Endpoint를 자유롭게 연결할 수 있다. MCP Tool, Git 기반 `SKILL.md`, Sandbox, Tool Approval, Ask-user Checkpoint, Context Compaction, Subagent, Deferred Tool Loading, Session State를 하나의 Runtime으로 제공한다.

개인용은 SQLite 한 프로세스로 실행할 수 있고 팀 배포는 Postgres+Redis, Docker Compose, Helm 등으로 확장된다. TrueFoundry는 여기에 AI Gateway, MCP Gateway, Skill Registry, RBAC, Budget, Rate Limit, Observability를 붙인 Hosted Enterprise Layer도 제공한다.

**왜 중요한지:** Agent 생태계에서 점점 중요한 경계가 `Model`과 `Harness` 사이에 생기고 있다. Harness가 표준화되고 오픈소스화되면 Claude, GPT, Gemini, GLM 같은 모델은 교체 가능한 실행엔진이 되고, 기업이 장기적으로 소유하는 자산은 Tool Permission, Skill, Sandbox Policy, Session State, Trace 같은 운영 계층이 된다. Kubernetes가 Application과 Infrastructure의 경계를 분리했던 것과 비슷한 변화다.

- GitHub: https://github.com/truefoundry/trueforge
- 공식 발표: https://www.truefoundry.com/press-room/truefoundry-launches-trueforge-an-open-source-vendor-neutral-alternative-to-claude-managed-agents

## 3. NVIDIA `PAIR` — 집에 남는 RTX·Mac·DGX Spark를 하나의 로컬 Agent 추론 Pool로

**핵심 요약:** 아직 이전 브리핑에서 다루지 않았던 NVIDIA의 `Personal AI Router PAIR`가 최근 오픈소스 공개 후 빠르게 주목받고 있다. 현재 GitHub 약 1.2K Stars이며 Apache 2.0이다. PAIR는 RTX Windows·Linux PC, DGX Spark, Mac M4 이상을 같은 LAN에서 묶고 Ollama 또는 LM Studio 요청을 사용 가능한 Node로 자동 Routing한다.

핵심은 여러 GPU를 하나의 거대한 가상 GPU로 합치는 것이 아니다. 각 요청은 한 Node에서 끝까지 실행되고, PAIR가 Model Availability와 현재 Workload를 보고 여러 독립 요청을 분산한다. 따라서 Multi-Agent처럼 동시에 많은 Inference Call을 만드는 Workload에 특히 잘 맞는다. 외부 Node 간 요청은 mTLS로 암호화하고, Application은 기존 Ollama 또는 OpenAI-compatible Endpoint를 그대로 사용할 수 있다.

**왜 중요한지:** Local AI가 `한 노트북에서 작은 모델 하나 실행`하는 단계에서 `집이나 소규모 팀의 여러 기기를 하나의 추론 Capacity Pool로 사용하는 단계`로 이동하고 있다. 특히 Agent는 병렬 Subagent와 Tool Loop 때문에 단일 요청의 속도보다 동시 처리량이 중요하다. PAIR는 남는 Consumer Hardware를 Agent Inference Cluster로 재활용하는 매우 현실적인 접근이다.

- NVIDIA 공식 페이지: https://www.nvidia.com/ko-kr/ai-on-rtx/personal-ai-router/
- GitHub: https://github.com/NVIDIA/Personal-AI-Router

## 4. NVIDIA × Palantir — NVIDIA 자신의 130만 부품 Supply Chain에 Sovereign AI를 먼저 배치

**핵심 요약:** NVIDIA와 Palantir가 9월 10일 NVIDIA Nemotron Open Model과 Palantir Foundry·AIP·Ontology를 결합한 Sovereign AI Stack을 발표했다. 첫 고객은 NVIDIA 자신이다. Vera Rubin Rack 한 대에 약 130만 개 부품이 들어가는 복잡한 공급망에서 제약조건 탐지, 운영지식의 지속적 Codification, 의사결정 지원을 Agent 형태로 적용한다.

같은 Stack은 Cloud와 On-prem 모두에 배포할 수 있도록 설계됐고 제조·제약·농업·유통·정부 등 복잡한 Supply Chain을 가진 조직을 대상으로 확장될 예정이다. 핵심 메시지는 기업의 Proprietary Data와 운영지식을 외부 모델 사업자에게 넘기지 않으면서 Open Model을 실제 Mission-critical Workflow에 연결하는 것이다.

**왜 중요한지:** Sovereign AI가 `우리 데이터센터에서 모델을 실행한다`는 수준을 넘어 `회사의 핵심 운영 프로세스와 의사결정 지식까지 내부에 축적한다`는 방향으로 확장되고 있다. Open-weight Model의 가장 강한 기업용 시장은 범용 Chat보다 Supply Chain, Manufacturing, Semiconductor 같은 Mission-critical Workflow일 가능성이 크다.

- NVIDIA·Palantir 발표: https://www.nasdaq.com/press-release/nvidia-and-palantir-bring-sovereign-intelligence-critical-supply-chains-2026-09-10

## 5. Enflame, Shanghai 데뷔 첫날 `+179%` — 중국 AI Chip 자본시장이 실제 대규모 자금 공급원으로

![Enflame AI chip](https://n.sinaimg.cn/sinakd20260214s/724/w915h609/20260214/123e-2244c9dade751e556c4a2ee3d262a134.png)

**핵심 요약:** Tencent가 투자한 중국 AI Chip 업체 Enflame가 9월 11일 Shanghai STAR Market 상장 첫날 179% 상승 마감했다. IPO로 61.2억 위안, 약 $912M을 조달했고 시가총액은 공모가 기준 612억 위안에서 종가 기준 약 1,710억 위안으로 뛰었다. 아직 적자기업이지만 올해 1～9월 매출은 23억～30억 위안으로 전년 대비 326%～455% 성장할 것으로 예상한다.

Tencent는 상장 후 약 17.95%를 보유한 최대주주이며 2025년 Enflame 매출의 약 84%를 차지한 최대 고객이기도 하다. IPO 자금은 차세대 AI Chip과 Computing System 개발에 투입된다.

**왜 중요한지:** 9월 8일 브리핑에서 중국의 이른바 `AI Chip 네 마리 용`을 다뤘는데, 이번 상장은 그 흐름의 중대한 후속이다. 중국의 AI 반도체 자립이 정부 지원과 연구개발에만 의존하는 것이 아니라 공개 자본시장에서 수십억 달러 규모의 자금을 끌어들이는 단계로 들어갔다. NVIDIA 대체재의 기술력만큼 `얼마나 빠르게 자본과 고객을 확보해 반복 개발할 수 있는가`가 중국 AI Compute 경쟁의 핵심 변수가 되고 있다.

## 이번 회차의 핵심

이번 다섯 소식을 연결하면 AI 경쟁의 중심이 `하나의 최고 모델`에서 전체 실행 구조로 이동하는 흐름이 더 강해졌다.

**Fugu Max·Ultra v2**는 여러 모델을 지휘하는 Orchestration 자체를 학습하고, **TrueForge**는 그 Agent Harness를 특정 모델 회사에서 분리한다. **PAIR**는 Agent Inference를 여러 로컬 기기로 분산하고, **NVIDIA×Palantir**는 Open Model을 실제 기업의 Mission-critical 운영지식에 연결한다. **Enflame**는 이 모든 Compute 경쟁을 뒷받침할 새로운 반도체 생태계에 대규모 자본이 유입되고 있음을 보여준다.

> **Agent 시대의 차별화 포인트는 Model 하나보다 Orchestration + Harness + Distributed Inference + Proprietary Workflow + Compute Supply Chain의 결합으로 이동하고 있다.**
