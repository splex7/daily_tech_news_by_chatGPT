## 1. Anthropic 공개 `Model Hardware Standard` — AI Agent가 실험실·공장 장비를 직접 조작

### 핵심 요약
Anthropic이 8월 27일 Model Hardware Standard, MHS의 연구 프리뷰를 공개했다. MHS는 AI Agent가 현미경, 액체 처리 장비, 로봇 팔 같은 물리 장비를 공통 인터페이스로 제어하도록 하는 표준이다. 프로그래밍 가능한 장비라면 적용할 수 있고, 모델에 종속되지 않으며 MCP 같은 표준 프로토콜을 통해 Agent Harness가 접근할 수 있다. Anthropic은 초기 파트너들과 안전 평가를 진행한 뒤 오픈소스로 공개할 계획이다.

### 왜 중요한가
MCP가 Agent와 소프트웨어 도구를 연결했다면 MHS는 그 개념을 물리 세계로 확장한다. Agent가 문서와 API만 조작하는 단계에서 실험·제조 장비를 직접 제어하는 단계로 이동한다는 의미다. 특히 장비별 통합에 몇 주～몇 달 걸리던 작업을 몇 시간～몇 분 수준으로 줄이는 것을 목표로 한다.

- https://www.anthropic.com/news/model-hardware-standard-research-preview

## 2. Google `Gemini Omni 1.1 Flash` 출시 — 생성형 비디오가 프로덕션 워크플로로 이동

### 핵심 요약
Google이 8월 27일 Gemini Omni 1.1 Flash를 공개했다. 최대 10초의 이전 영상을 참고해 장면을 이어 붙일 수 있고, 10초 단위로 최대 40초까지 확장할 수 있다. 시작 프레임과 마지막 프레임을 지정한 보간, 최대 3초의 참조 비디오 입력, 1080p·4K 업스케일링을 지원한다. 360p Draft 모드는 720p 대비 최대 60% 빠르고 비용은 약 3분의 1이다. Gemini API와 Google AI Studio에서 개발자가 사용할 수 있다.

### 왜 중요한가
AI 비디오 경쟁이 단순한 한 번의 생성에서 편집 가능한 제작 파이프라인으로 이동하고 있다. 초안은 저렴한 해상도로 여러 번 생성하고 최종 결과만 고해상도로 올리는 방식이 API 차원에서 제공되기 시작했다. 영상 생성 비용과 반복 작업을 분리하는 구조는 실제 상업 제작에 중요한 변화다.

## 3. Hugging Face·Pollen Robotics `Microduck` 공개 — $399 Physical AI 개발 플랫폼

### 핵심 요약
Hugging Face 산하 Pollen Robotics가 25cm 크기의 이족 보행 로봇 Microduck을 $399에 공개했다. 15개 모터, 카메라, LiDAR, 두 개의 IMU를 탑재하며 걷기, 앉기, 물건 집기, 넘어졌다가 일어나기, 롤러스케이트 등의 동작을 수행한다. 핵심은 SDK·시뮬레이션·강화학습·sim-to-real 소프트웨어 스택이 오픈소스라는 점이다. 사용자는 시뮬레이션에서 새로운 행동을 학습시킨 뒤 실제 로봇에 배포할 수 있다.

### 왜 중요한가
로봇 AI에서 가장 큰 진입 장벽은 비싼 하드웨어와 데이터 수집 환경이었다. Microduck은 Physical AI 실험을 소비자 GPU와 수백 달러 수준의 로봇으로 내려오게 하려는 시도다. 모델을 Hugging Face Hub에서 공유하듯 로봇 행동 정책도 공유하는 생태계를 만들려는 방향이 특히 주목된다.

## 4. GitHub 주목 프로젝트 `DeepSeek Harness` — Agent = Model + Harness를 전면에

### 핵심 요약
DeepSeek의 MIT 라이선스 오픈소스 Agent Runtime인 DeepSeek Harness가 GitHub에서 계속 빠르게 확산되고 있다. 핵심 설계는 `Everything is a plugin`이다. 모델, 도구, Skills, Session, Sandbox, Storage, Loop, Scheduling, UI를 모두 교체 가능한 플러그인으로 구성한다. 또한 system prompt, reasoning, tool call, subagent scheduling 등을 append-only session log에 남겨 실행을 resume·fork·search·replay할 수 있다.

### 왜 중요한가
2026년 Agent 경쟁에서 모델과 Harness를 분리해서 보는 관점이 빠르게 정착되고 있다. Claude Code나 Codex가 완성품 Agent라면 DeepSeek Harness는 Agent 자체를 조립하는 Runtime에 가깝다. 모델이 빠르게 교체되는 환경에서는 장기적으로 Harness·Tool·Skill·Execution Log 계층의 가치가 더 커질 수 있다.

Sources:
- https://deepseek.com/harness/en/
- https://github.com/deepseek-ai/deepseek-harness

## 5. Anthropic, Nscale과 약 `$45B` 규모 Compute 계약 — AI 경쟁의 병목은 전력·데이터센터

### 핵심 요약
Reuters와 Financial Times 보도에 따르면 Anthropic은 영국 AI 인프라 업체 Nscale의 미국 웨스트버지니아 데이터센터에서 약 460MW의 AI Compute를 6년 동안 임대하는 약 450억 달러 규모 계약을 맺었다. 해당 인프라는 NVIDIA의 차세대 Vera Rubin 시스템을 사용하며 2027년 말부터 공급될 전망이다.

### 왜 중요한가
Frontier AI 기업의 경쟁은 이제 모델 알고리즘뿐 아니라 몇 년 뒤 사용할 GPU와 전력을 미리 확보하는 경쟁이 됐다. Anthropic이 소유 데이터센터 대신 대규모 장기 임대 계약을 연속 체결하는 것은 AI Compute가 클라우드 사용량이 아니라 장기 인프라 자산처럼 거래되기 시작했다는 신호다.
