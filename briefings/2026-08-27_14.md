## 1. NVIDIA, Hugging Face를 129억 달러에 인수하기로 합의했다는 보도

### 핵심 요약
Reuters는 The Information을 인용해 NVIDIA가 Hugging Face를 129억 달러에 인수하기로 합의했다고 보도했다. Hugging Face는 오픈웨이트 모델, 데이터셋, Transformers·Diffusers 같은 핵심 라이브러리를 연결하는 사실상 오픈 AI 생태계의 허브다. 다만 현재 시점에는 NVIDIA와 Hugging Face의 공식 발표나 논평은 나오지 않았다.

### 왜 중요한지
단순한 소프트웨어 인수가 아니라 NVIDIA가 GPU·네트워크·CUDA에 이어 모델 배포·개발 커뮤니티 레이어까지 수직 통합하려는 움직임으로 볼 수 있다. 성사될 경우 Hugging Face가 지금까지 유지해온 하드웨어 중립성, 특히 AMD·Intel·여러 클라우드와의 관계가 어떻게 바뀔지가 핵심이다.

## 2. Perceptron `Isaac 0.5` 공개 — 36B 오픈웨이트 embodied foundation model

### 핵심 요약
전 Meta FAIR 연구진이 세운 Perceptron이 Isaac 0.5를 공개했다. 36B sparse model로 이미지·비디오·언어 명령·로봇 상태·과거 행동을 함께 받아 비디오 이해, 공간 grounding, task progress, 미래 지각 예측, 로봇 제어를 하나의 backbone에서 처리한다. 학습에는 35개 이상 로봇 시스템, 10만 시간의 robot experience, 100만 시간의 일반 비디오, 3조 multimodal token이 사용됐다고 공개했다. 코드 저장소는 Apache 2.0이며 모델 weights도 공개돼 있다.

Perceptron은 일반 비디오 학습량을 1,000시간에서 100만 시간으로 늘렸을 때 특정 action-loss 목표에 필요한 teleoperation 데이터가 약 5,900시간에서 28시간으로 줄었다고 보고했다.

### 왜 중요한지
LLM의 다음 확장 영역인 Physical AI에서 오픈웨이트 모델이 본격적으로 등장하는 신호다. 특히 perception·reasoning·control을 따로 붙이는 것이 아니라 하나의 sparse backbone으로 통합하려는 방향은 향후 범용 로봇 stack의 중요한 경쟁축이 될 수 있다.

## 3. LangChain, Deep Agents v0.7·Managed Deep Agents·LLM Gateway를 생산환경 중심으로 묶는다

### 핵심 요약
LangChain의 8월 업데이트에서 Managed Deep Agents와 LLM Gateway가 public beta 단계에 들어갔고, Deep Agents v0.7은 비슷한 성능을 유지하면서 base input token을 65% 줄였다고 발표했다. Managed Deep Agents는 durable execution, sandbox, tracing 등을 포함하며, LLM Gateway는 비용 제한, rate limit, model fallback, sensitive data handling을 제공한다. LangSmith BYOC도 AWS에서 제공된다.

### 왜 중요한지
Agent 개발의 병목이 점점 모델 자체보다 실행 인프라로 옮겨가고 있다는 사례다. 특히 `Agent → LLM Gateway → 여러 모델` 구조가 관측성·비용·보안·fallback을 묶는 표준적인 production 패턴으로 굳어지고 있다. Deep Agents의 65% token 절감은 장시간 agent loop에서 직접적인 비용 차이를 만든다.

Sources:
- LangChain newsletter: https://www.langchain.com/blog/august-2026-langchain-newsletter
- LLM Gateway: https://www.langchain.com/blog/langsmith-llm-gateway-runtime-controls-for-production-agents

## 4. GitHub에서 `Agent Skills`가 별도 생태계로 급부상

### 핵심 요약
GitHub Trending에서 agent skill 계열 저장소가 두드러지고 있다. `tt-a1i/archify`는 오늘 GitHub Trending 기준 약 1,000 stars/day 수준으로 상승했으며, 코드베이스나 시스템 설명을 architecture·workflow·sequence·data-flow diagram으로 바꾸는 cross-agent skill이다. Claude Code, Codex CLI, Cursor, OpenCode 등에 공통으로 사용할 수 있다.

Anthropic이 관리하는 `anthropics/claude-plugins-official`도 Trending에 올라와 있으며, Anthropic 내부 plugin과 서드파티 plugin을 한 디렉터리에서 배포한다. plugin은 skills, commands, agents, hooks, MCP integration을 묶는 단위로 발전하고 있다.

### 왜 중요한지
2025년의 MCP가 `Agent가 무엇에 접근할 수 있는가`를 표준화했다면, 2026년에는 Skills/Plugins가 `Agent가 일을 어떻게 수행하는가`를 재사용 가능한 단위로 표준화하는 흐름이 강해지고 있다. 모델보다 skill package를 옮겨 다니는 것이 중요해질 가능성이 크다.

Sources:
- GitHub Trending: https://github.com/trending
- Archify: https://github.com/tt-a1i/archify
- Anthropic official plugins: https://github.com/anthropics/claude-plugins-official

## 5. 개인 Agent `Instinct`, 25억 달러 가치로 2.5억 달러 Series B

### 핵심 요약
WSJ와 TechCrunch에 따르면 개인 AI assistant Instinct가 2.5억 달러 Series B를 조달하며 기업가치 25억 달러를 인정받았다. 총 조달액은 3.5억 달러 수준이다. Instinct는 사용자의 이메일·앱·기기 등에 연결해 문자나 전화 명령으로 예약, 쇼핑, 일정 관리, 구독 취소 같은 실제 행동을 수행하는 personal agent를 지향한다.

아직 private beta인데도 빠르게 큰 투자를 받은 반면, 광범위한 앱·개인 데이터 접근 권한 때문에 privacy 우려도 함께 제기되고 있다.

### 왜 중요한지
개인 Agent 시장의 경쟁 기준이 대화 품질에서 실제 행동 수행력과 권한 관리로 이동하고 있다는 신호다. 동시에 장기간 지속되는 personal agent가 성공하려면 memory, permission, audit, data governance가 핵심 제품 기능이 된다는 점도 보여준다.
