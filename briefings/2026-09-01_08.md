## 1. Tencent `Hy4 preview` 오픈소스 — 770B MoE, 49B 활성, 1M+ 컨텍스트

### 핵심 요약
Tencent가 8월 28일 `Hy4 preview`를 공개하고 오픈소스화했다. 전체 770B 파라미터 가운데 49B가 활성화되는 구조이며 1M 토큰을 넘는 컨텍스트를 지원한다. Tencent는 코딩, 오피스 업무, 금융 분석, 과학 연구 등 실제 생산성 업무를 중심으로 모델을 설계했다고 설명했다. Tencent 내부 블라인드 평가에서는 163명의 전문가와 203개 엔지니어링 과제를 대상으로 평균 2.99/4.00을 기록해 GLM-5.3과 Kimi K3를 소폭 앞섰다고 발표했다. 이 수치는 업체 자체 평가이므로 독립 검증이 필요하다.

Tencent는 Hy4가 자신의 학습 방법, 데이터 전략, 평가 체계와 저수준 연산 최적화에도 참여했다고 밝혔으며, 추론 병목을 분석해 기준 대비 end-to-end throughput을 31.8% 높였다고 주장했다. API 가격은 입력 100만 토큰당 $0.834, 출력 $2.501이다.

### 왜 중요한지
오픈 모델 경쟁이 단순 파라미터 규모에서 `큰 전체 모델 + 적은 활성 파라미터 + 긴 컨텍스트 + Agent 업무 최적화`로 이동하고 있다. 1M급 컨텍스트와 비교적 낮은 API 비용은 긴 코드베이스나 다문서 업무를 처리하는 Agent에서 특히 의미가 있다. 또한 모델이 학습과 추론 인프라의 일부 최적화에 직접 참여했다는 Tencent의 실험은 AI 개발 과정 자체가 Agent화되는 방향을 보여준다.

## 2. Perceptron `Isaac 0.5` — 영상 이해부터 로봇 행동까지 하나의 36B 오픈웨이트 모델로

### 핵심 요약
Perceptron AI가 `Isaac 0.5`를 공개했다. 36B sparse embodied foundation model로 이미지, 비디오, 자연어 지시, 로봇 상태와 과거 행동을 입력받아 영상 이해, 객체 위치와 추적, 작업 진행 상태 추론, 실제 로봇 행동 생성을 하나의 모델에서 수행한다.

Isaac은 35개가 넘는 로봇 시스템의 10만 시간 로봇 경험, 100만 시간 일반 비디오, 3조 개의 멀티모달 토큰으로 학습됐다. Perceptron의 통제 실험에서는 일반 영상 데이터를 1,000시간에서 100만 시간으로 늘렸을 때 동일한 action-loss 수준에 필요한 teleoperation 데이터가 약 5,900시간에서 28시간으로 줄었다. 약 210배 감소라는 결과지만 역시 연구팀 자체 결과라는 점은 감안해야 한다. 코드 저장소는 Apache 2.0이며 모델 가중치도 공개돼 있다.

### 왜 중요한지
Physical AI의 가장 큰 비용 중 하나는 실제 로봇 데이터를 모으는 일이다. Isaac의 핵심 주장은 일반 비디오에서 배운 시각·공간 지식이 실제 로봇 학습에 상당 부분 이전될 수 있다는 것이다. 이 방향이 재현된다면 로봇 모델의 발전 방식이 `많은 실제 로봇 시연을 직접 수집`하는 방식에서 `대규모 일반 영상 + 적은 현장 데이터로 적응`하는 방식으로 바뀔 수 있다. 오픈웨이트 모델이기 때문에 제조, 물류, 창고 자동화 팀이 자체 장비와 데이터에 맞춰 실험할 수 있다는 점도 크다.

## 3. `OpenClaw 2.0` — 개인 Agent에서 멀티디바이스·공유 세션 Agent Runtime으로

### 핵심 요약
OpenClaw가 8월 30일 프로젝트 역사상 가장 큰 업데이트인 `OpenClaw 2.0`을 공개했다. 공식 발표에 따르면 933명의 기여자가 참여했고 이 가운데 569명은 첫 기여자였으며, 16,000개가 넘는 Pull Request가 이번 버전에 포함됐다.

이번 버전은 설치, 메시징, 메모리, Skill, 모델, 자동화, 브라우저, 네이티브 앱, 플러그인, 보안을 전반적으로 재구성했다. 특히 Shared Cloud Sessions를 통해 다른 사람에게 Agent 작업을 넘기거나 실시간으로 같은 Context를 공유할 수 있게 됐고, 브라우저 앱도 장기 작업을 계속 추적하는 첫 번째 수준의 인터페이스로 재설계됐다. 기존 ChatGPT·Claude 구독, API Key, Local Model을 활용한 초기 설정도 단순화했다.

### 왜 중요한지
Agent Runtime이 `한 사람이 채팅으로 명령하는 개인 비서`에서 `여러 기기와 여러 사람이 동일한 Context를 공유하는 지속형 작업 공간`으로 변하고 있다. 실제 조직에서 Agent를 쓰려면 모델 성능뿐 아니라 Session 이동, 협업, 권한, Credential, 장기 상태가 필요하다. OpenClaw 2.0은 Agent가 하나의 앱 기능이 아니라 새로운 업무 Runtime으로 발전하는 모습을 보여준다.

## 4. `halo-record` — AI Agent 행동을 해시체인으로 검증하는 오픈소스 감사 로그

### 핵심 요약
오픈소스 Python 프로젝트 `halo-record`가 AI Agent의 tool call, model call, 데이터 접근, 승인 기록을 append-only 로그로 남기고 각 행에 이전 행의 hash를 연결하는 방식을 제시했다. 나중에 로그를 수정하거나 순서를 바꾸면 뒤의 hash chain이 깨지기 때문에 제3자가 별도의 vendor 계정이나 key 없이 무결성을 확인할 수 있다.

Raw argument는 기록하지 않고 값을 hash 처리하거나 redacted summary로 저장하며 OpenTelemetry, LangChain, MCP Server와 Gateway 로그를 받아들이는 adapter도 제공한다. 다만 hash chain 자체는 `기록된 로그가 변조되지 않았다`는 것은 증명하지만 `모든 행동이 빠짐없이 기록됐다`는 것까지 보장하지는 않는다. 이를 보완하기 위해 외부 witness가 주기적으로 record count와 head hash를 저장하는 구조도 제안한다.

### 왜 중요한지
Agent가 실제 고객 데이터와 기업 시스템을 조작하기 시작하면 일반 애플리케이션 로그만으로는 충분하지 않다. 앞으로 기업은 `Agent가 무엇을 했다고 주장하는가`가 아니라 `Agent가 무엇을 했는지 제3자가 검증할 수 있는가`를 요구하게 될 가능성이 높다. Agent IAM, Sandbox, MCP Gateway에 이어 tamper-evident audit trail이 Agent Infrastructure의 또 하나의 기본 계층이 될 수 있다.

## 5. ChatGPT Ads, 출시 200일도 안 돼 연환산 $1B — AI 대화창이 새로운 광고 유통채널로

### 핵심 요약
OpenAI는 8월 31일 ChatGPT Ads가 출시 후 200일이 채 되기 전에 연환산 매출 run rate $1B에 도달했다고 발표했다. 현재 수만 개 광고주가 사용하고 있고 광고는 40개가 넘는 국가에서 제공된다. 인도, 유럽, 중동, 북아프리카에서도 self-service Ads Manager가 확대된다. OpenAI는 광고 지원 무료 티어가 주간 활성 사용자 10억 명 이상에게 ChatGPT 접근을 제공하는 사업 구조의 한 축이라고 설명했다.

ChatGPT 광고는 키워드만 보는 것이 아니라 현재 대화의 Context를 활용해 관련 광고를 선택하며 국가와 사용자 설정에 따라 더 넓은 ChatGPT 경험의 Context도 사용할 수 있다. OpenAI는 광고는 답변과 명확히 분리되고 답변 생성에는 영향을 주지 않으며 광고주가 사용자의 비공개 대화를 받지 않는다고 명시했다.

### 왜 중요한지
AI 비즈니스가 `구독 + API`에서 `구독 + API + 광고`로 빠르게 확장되고 있다. 검색 광고가 사용자의 짧은 키워드를 구매 의도 신호로 활용했다면 대화형 AI는 목표, 조건, 예산, 비교 기준이 담긴 훨씬 풍부한 Context를 가질 수 있다. ChatGPT가 단순 답변 도구를 넘어 제품 탐색과 구매 의사결정의 플랫폼이 된다면 Google Search와 소셜 광고 시장의 일부를 직접 겨냥하는 새로운 유통 채널이 될 수 있다.

## 이번 회차 핵심 흐름

이번 회차를 관통하는 변화는 `AI가 무엇을 말하느냐`보다 `AI가 어떤 환경에서 실제로 일하고, 행동하고, 검증되며, 돈을 버느냐`가 중요해지고 있다는 점이다.

`Hy4`는 Agent용 모델의 비용·Context 경쟁을, `Isaac 0.5`는 AI가 현실 세계의 행동으로 넘어가는 Physical AI를, `OpenClaw 2.0`은 지속형 Agent Runtime을, `halo-record`는 그 행동의 검증 계층을, `ChatGPT Ads`는 AI 인터페이스 자체가 거대한 비즈니스 유통 채널이 될 수 있음을 보여준다.

> Model → Agent Runtime → 실제 행동 → Audit → Business Distribution

AI 경쟁은 모델 성능 하나가 아니라 이 전체 Stack을 누가 더 잘 연결하고 운영하느냐의 경쟁으로 이동하고 있다.
