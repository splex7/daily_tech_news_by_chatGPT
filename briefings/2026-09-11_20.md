## 1. OpenAI `Agents API` 공개 — Codex의 Harness와 장기 실행 인프라를 API로

![OpenAI Agents API 관련 화면](https://pypi-camo.freetls.fastly.net/7d9b7155bd0f0413261ff520a82a3033129dd552/68747470733a2f2f63646e2e6f70656e61692e636f6d2f4150492f646f63732f696d616765732f6f726368657374726174696f6e2e706e67)

**핵심 요약:** OpenAI가 9월 10일 `Agents API`를 Public Beta로 공개했다. 핵심은 단순한 모델 호출 API가 아니라 Codex에서 사용해온 Agent Harness와 장기 실행 인프라를 개발자가 그대로 이용할 수 있게 한 것이다. OpenAI가 Harness를 운영하고 개발자는 OpenAI Hosted Sandbox, 자체 인프라, 또는 Cloudflare·E2B·Modal·Vercel 등 파트너 환경을 선택할 수 있다.

장시간 작업을 위해 여러 Context Window를 넘나드는 자동 Compaction을 제공하며, Tool Search로 필요한 Tool Definition만 동적으로 불러와 Context와 Token 사용량을 줄인다. MCP, Custom Function, Web Search를 지원하고 Programmatic Tool Calling으로 여러 호출을 병렬 실행하거나 Code에서 결과를 필터링할 수 있다. Multi-Agent 기능은 작업을 Subagent에 분산해 병렬 처리한다. Public Beta에서는 Agents API 자체에 별도 요금이 없고 사용한 Token과 Tool 비용만 지불한다.

**왜 중요한지:** Agent 제품의 차이를 만드는 요소가 Foundation Model 하나에서 `Harness + Context 관리 + Sandbox + Tool Runtime + Subagent Orchestration`으로 이동하고 있다. 지금까지 각 회사가 직접 구현해야 했던 이 계층을 OpenAI가 관리형 서비스로 제공하기 시작했다는 것은 Agent 개발의 추상화 수준이 한 단계 올라갔다는 뜻이다. Kubernetes가 Container 실행을 플랫폼화했듯, Agent Harness도 독립된 Infrastructure Product가 되는 흐름이다.

- 공식 발표: https://openai.com/index/introducing-the-agents-api/

## 2. OpenAI `GPT-Live-1` API 출시 — 듣고 말하는 동안 뒤에서 다른 Agent가 일한다

![GPT-Live-1](https://best.xiaohu.ai/covers/openai-gpt-live-launch.jpg)

**핵심 요약:** OpenAI가 9월 10일 `GPT-Live-1`을 API로 출시했다. 이 모델은 사용자의 말을 들으면서 동시에 말할 수 있는 Full-Duplex Voice Model이며, 대화를 유지하는 동안 복잡한 추론이나 Tool 사용은 GPT-6 Astra 또는 개발자가 선택한 다른 Backend Model·Agent에 위임할 수 있다.

OpenAI 평가에서 Full Duplex Bench는 GPT-Realtime-2.1 대비 30%p 개선됐고, Speak의 초기 평가에서는 기존 Turn-based 방식보다 불필요한 대화 중단이 거의 80% 줄었다. ASR Transcript와 Response Text를 기본 제공하며 Keyword Biasing, Turn Detection, WebRTC, WebSocket, Telephony를 지원한다. Front-end Voice Layer 가격은 분당 $0.05다.

**왜 중요한지:** Voice Agent Architecture가 `STT → LLM → TTS`의 직렬 Pipeline에서 `Realtime Conversation Model + Backend Reasoning Agent` 구조로 바뀌고 있다. 사용자는 자연스럽게 대화하고, 무거운 추론과 Tool Call은 뒤에서 별도 Agent가 처리한다. 즉 모든 Intelligence를 하나의 거대한 Multimodal Model에 넣는 대신, 실시간 상호작용과 깊은 추론을 전문 계층으로 분리하는 구조가 현실적인 Production Pattern으로 자리 잡기 시작했다.

- 공식 발표: https://openai.com/index/introducing-gpt-live-1-in-the-api/

## 3. Anthropic 9월 Threat Intelligence Report — Cyber Attack도 Model 탈취도 Agent화

![AI 기반 공격 체인 관련 이미지](https://images.ctfassets.net/o33dj4ooyjty/4vnZCkwdyFQ8nZb9G1f9YI/c7bfa4a8453e140638732a565ecafb4c/chart-mythos-attack-chain.png)

**핵심 요약:** Anthropic이 9월 10일 공개한 Threat Intelligence Report는 2025년 12월～2026년 8월 적발한 악용 사례를 Cyber Operation, Surveillance, Influence Operation, Scam, Biological Misuse, Conventional Weapons, Illicit Distillation 등 7개 영역으로 정리했다. Anthropic은 보고서에 포함된 Cyber Operation의 다수가 단순 Chat 질의가 아니라 AI가 정찰·취약점 공격·데이터 유출을 직접 실행하거나 Multi-Agent Framework를 통해 조율하는 형태였다고 밝혔다.

또 하나의 큰 축은 경쟁사의 Model Distillation이다. Reuters가 보고서를 바탕으로 보도한 내용에 따르면 Anthropic은 Alibaba 계열 활동에서 2026년 5월～7월 1억5,100만 회가 넘는 비정상 Interaction을 추적했다고 주장했다. Moonshot과 Zhipu 관련 사례도 대규모 Fraudulent Account와 자동화된 Query Pipeline을 이용해 Claude의 Capability와 Chain-of-Thought 성격의 데이터를 추출하려 한 것으로 보고됐다. 각 회사의 반론과 Distillation 자체가 합법적으로도 널리 사용되는 기술이라는 점은 별도로 구분할 필요가 있다.

**왜 중요한지:** AI 보안의 대상이 `사용자가 모델에 나쁜 질문을 하는가`에서 두 방향으로 확장되고 있다. 첫째, Agent Framework가 Cyber Kill Chain 전체를 자동화해 공격 실행 비용을 낮춘다. 둘째, Frontier Model의 출력 자체가 경쟁사의 Training Data가 될 수 있어 API Abuse Detection과 Model IP Protection이 핵심 사업 인프라가 된다. Agent 시대의 Security는 Prompt Filtering만으로는 부족하고 Identity, Rate Pattern, Tool Execution, Autonomous Behavior, Distillation Detection까지 함께 봐야 한다.

## 4. 🔥 GitHub `OpenMAIC` — 한 문서가 AI 교사·조교·학생이 있는 ‘Agent 교실’로

![OpenMAIC](https://openmaic.chat/imgs/og-image.png)

**핵심 요약:** Tsinghua University의 `THU-MAIC/OpenMAIC`가 GitHub Trending에서 계속 빠르게 성장하고 있다. 9월 10일 추적 기준 약 34.5K Stars이며 최근 한 주에 약 3.5K Stars가 늘었다. 현재 핵심 버전은 8월 27일 공개된 v1.0.0이다.

OpenMAIC는 Topic이나 PDF·문서·Audio·Video를 넣으면 AI Teacher, Teaching Assistant, AI Classmate가 참여하는 Interactive Course를 자동 생성한다. Slides, Quiz, HTML Simulation, PBL, Whiteboard, TTS를 한 환경에서 사용한다. v1.0에서는 Chat 기반 Agent Workbench, 재시작 후에도 이어지는 Durable Session, 실행 중 Cancel·Resume·Steer, Session Materials, 20개의 Built-in Skill, Provider-neutral Runtime이 추가됐다. `SKILL.md` 형식의 OpenMAIC Skill을 OpenClaw, Codex, DeepSeek, WorkBuddy 등 다른 Agent Workbench에서도 사용할 수 있다.

**왜 중요한지:** Multi-Agent가 Backend의 추상적인 Orchestration Pattern을 넘어 최종 사용자가 직접 경험하는 Product UI가 되고 있다. 더 중요한 점은 교육이라는 Domain Knowledge와 Workflow가 특정 LLM에 묶이지 않고 Skill과 Runtime으로 패키징된다는 것이다. Model은 교체할 수 있지만 `수업을 어떻게 설계하고, 어떤 역할의 Agent를 배치하고, 어떤 Interaction을 제공할 것인가`라는 Workflow는 계속 남는다. 이는 교육뿐 아니라 컨설팅, 온보딩, 훈련, 시뮬레이션 같은 분야에도 그대로 확장 가능한 패턴이다.

- GitHub: https://github.com/THU-MAIC/OpenMAIC
- 프로젝트: https://openmaic.chat/

## 5. Positron AI, `$875M` 조달·기업가치 `$5B` — Agent 시대의 병목을 FLOPS가 아닌 Memory로 본다

![Positron AI Accelerator](https://cdn.mos.cms.futurecdn.net/vXP74UDNTsre6sF7xfNKYD.jpg)

**핵심 요약:** AI Inference Chip 스타트업 Positron AI가 9월 10일 Series C에서 $875M을 조달했고 기업가치는 $5B로 평가됐다. Reuters에 따르면 불과 7개월 전인 2026년 2월 $1.06B이었던 평가액의 4배 이상이다. 투자에는 QIA, NEA, Atreides Management, Valor Equity Partners 등이 참여했다.

Positron의 전략은 Inference가 Compute보다 `Memory Capacity + Memory Bandwidth + Power`에 더 크게 제약된다는 데서 출발한다. 차세대 Asimov Accelerator는 회사 사양 기준 Chip당 최대 2.3TB Memory를 목표로 하며, 4개 또는 8개의 Asimov를 사용하는 Titan System은 최대 18.4TB의 Accelerator-attached Memory와 1,000만 Token 이상의 Context를 겨냥한다. 모두 2027년 출시 예정이며 성능·효율 수치는 아직 회사 자체 주장이라는 점은 감안해야 한다.

**왜 중요한지:** Agent는 짧은 Chat보다 긴 Context, 큰 KV Cache, 여러 Agent의 동시 상주, 반복적인 Decode가 훨씬 많다. 그래서 Agent 사용량이 커질수록 최고 FLOPS보다 `얼마나 많은 Model과 Context를 Memory에 유지하면서 Token을 싸고 빠르게 생성하는가`가 경제성을 결정할 수 있다. NVIDIA 중심의 Training GPU 경쟁과 별개로, Agent Inference에 특화된 Memory-first Accelerator 시장이 독립적인 대형 산업으로 성장할 가능성을 보여주는 투자다.

## 이번 회차의 핵심

이번 다섯 소식은 Agent Stack이 빠르게 독립적인 산업 계층으로 분화되고 있음을 보여준다.

**Agents API**는 Harness와 Sandbox를 플랫폼화하고, **GPT-Live-1**은 실시간 대화와 Backend Reasoning을 분리한다. **Anthropic Threat Report**는 공격과 Model 탈취까지 Agent화되고 있음을 보여주며, **OpenMAIC**는 Domain Workflow 자체를 Multi-Agent Product로 패키징한다. 마지막으로 **Positron**은 이 모든 장시간 Agent를 돌릴 Inference Hardware를 Memory 중심으로 다시 설계하려 한다.

> **Agent 시대의 경쟁 단위는 LLM 하나가 아니라 Harness + Realtime Interface + Security + Domain Workflow + Inference Infrastructure의 결합으로 이동하고 있다.**
